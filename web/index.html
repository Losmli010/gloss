选中文字，即出译文

划词翻译是高频打扰式交互，Gloss 的答案只有四个字：快、清、小、稳。

划词即译

鼠标选中文字，浮层即刻弹出，无需切换窗口、无需粘贴。

LLM 流式

大模型流式输出，边生成边显示，随时取消、陈旧结果自动丢弃。

纯本地轻量

纯 Rust + WebGPU 原生渲染，单进程、无浏览器内核，常驻几乎无感。

macOS 原生

原生划词手势与全局热键，贴合系统体验，界面随系统语言切换。

下载 Gloss

免费开源（MIT），支持 Apple Silicon 与 Intel 芯片的 Mac。

下载 Apple Silicon 版（.dmg） 下载 .zip 备用 GitHub Releases 历史版本

无法获取最新版本信息，已切换到 GitHub Releases 页面下载（资产名含版本号，请按架构选择）。

首次打开指引

  1. 打开下载的 .dmg，把 Gloss 拖入「应用程序」；
  2. 在「应用程序」中右键点击 Gloss → 打开，再点「打开」确认；
  3. 之后即可正常双击启动。

当前安装包为 ad-hoc 签名，尚未做 Developer ID 公证，首次打开需以上方式放行。
