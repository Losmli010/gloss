工程克制

把常驻工具做到无感

翻译是高频打扰式交互，Gloss 用一套克制的纯 Rust 技术栈托住它。

单进程四线程，通道贯穿始终

主线程渲染、平台事件线程取材、鼠标监听线程收口、tokio 后台跑网络与缓存。事件经四条通道单向流动，带代数标记：陈旧响应在主线程被直接丢弃。

平台事件线程热键 · 划词取材
→
主线程winit + wgpu + egui
→
tokio 后台LLM 流式 · 缓存
→
结果浮层流式渲染 · 可取消

WebGPU 渲染

wgpu 走 Metal，egui 即时模式绘制。没有浏览器内核，内存与启动开销天然就小。

流式 & 可取消

SSE 边生成边显示；重新划词自动取消上一次任务，竞速结果只留最新。

本地缓存

相同内容直接复用结果，有效期可调；退出即清空，不留痕迹。

密钥进钥匙串

API Key 只存 macOS Keychain，不经配置快照传递，日志与错误消息零泄漏。

全局热键

选中文字按下热键即触发；任务开关逐项可控，关掉的任务不再响应。

随系统语言

界面文案内置中英双语，跟随系统语言切换，无需重启。

自动检查更新

启动静默检查新版本，设置页一键下载替换；更新清单由 CI 签发生成。

首次打开指引

  1. 打开下载的 .dmg，把 Gloss 拖入「应用程序」；
  2. 在「应用程序」中右键点击 Gloss → 打开，再点「打开」确认；
  3. 之后即可正常双击启动。

当前安装包为 ad-hoc 签名，尚未做 Developer ID 公证，首次打开需以上方式放行。
