## 窗口标题（APP_NAME 与 show_settings 的 title 入参）

- 2026-09-22 设置窗标题从写死的“Gloss 设置”改为调用方按界面语言给（`Text::app.settings_title`），两处窗口创建期的标题统一用 `APP_NAME`（品牌不进文案表，不翻译）。
- 为什么标题在 `show_settings` 时写一次，而不是逐帧比对语言再写：设置窗是**创建即隐藏**的（可见之前必然先过一次 `show_settings`），而窗内文案取自同一份快照语言——语言要保存才生效（与主题同一条路径）。因此“打开时写一次”与窗内文案始终同语，无需缓存上一次施加的语言；逐帧调 `set_title` 反而要引入缓存与平台调用开销。

## 设置窗窗口层级（AlwaysOnTop）

- 浮层是置顶层窗口（内容即窗口的划词卡片，必须浮于其它应用之上）；
  设置窗原先用默认层级——macOS 里低层级窗口无论聚焦与否都压不过高层
  级窗口，浮层可见时设置窗永远被卡片盖住（owner 真机反馈）。
- 修法：设置窗同为 `WindowLevel::AlwaysOnTop`。同层窗口按激活序排布：
  聚焦设置窗即浮于浮层上；点浮层则浮层回上层。任务在设置窗打开期间
  完成时，浮层出现在设置窗之后——owner 已认可该取舍（docs/14 §八.8）。

## 常量（尺寸与阈值）

- `APP_NAME`：应用名：浮层标题与设置窗创建期的占位标题（品牌不进文案表，不翻译）。
- `OVERLAY_WIDTH`：浮层宽度：与绘制侧的布局宽同源（`popup::WIDTH`），这里只转成窗口坐标的 `f64`（宽度不随内容变化，见 popup 模块）。
- `OVERLAY_HEIGHT`：浮层默认高度：典型最小内容（头部 + 三四行释义 + 页脚）的自然高度，约 `OVERLAY_WIDTH` / φ（296.6 取整）。内容结构变化导致偏离时优先跟内容走，不回头凑比例。
- `WORK_AREA_MARGIN`：自适应高度的屏幕余量：winit 不提供工作区（work area），按显示器逻辑高减去该值近似（菜单栏/Dock 的保守估计）。
- `HEIGHT_CAP_FRACTION`：高度钳制的屏幕占比：1/φ² = 0.382——弹窗是划词旁注，从属于底层应用，最大只占屏高 38.2%（先取占比再扣 `WORK_AREA_MARGIN`），更长内容更早交给内容侧滚动兜底。推论：逻辑高 ≤ 约 1026 的屏（含主流笔记本）上限即 `OVERLAY_HEIGHT`，浮层零增长余量、长文立刻滚动，这是占比取值的预期行为，不是缺陷。
- `RESIZE_EPSILON`：浮层尺寸变化小于该阈值不重设窗口（防 egui 布局与 winit resize 的帧迟滞来回抖动）。
- `STREAM_HEIGHT_STEP`：流式期间的增高步长（逻辑点）：逐 chunk 的内容增长被量化成台阶，避免每个增量都触发一次窗口 resize。
- `DRAG_POSITION_EPSILON`：拖动落点小于该阈值（逻辑点）不重设窗口：指针未动或贴边钳制的帧不做无谓的平台调用。
- `SETTINGS_WIDTH` / `SETTINGS_HEIGHT`：设置窗口尺寸：全部配置区块一屏放下的紧凑初值（可拖拽调整），`高:宽` ≈ φ。`pub(crate)` 供设置窗测试夹具取同一尺寸，防夹具与真实默认值脱钩。

## debounced_size（流式防抖尺寸）

- 宽度保持当前值（浮层宽度固定，见 `popup::WIDTH`），高度向上量化到 `STREAM_HEIGHT_STEP` 的倍数且相对当前值**只增不减**——内容回缩留给完成态的精确重排。

## capped_height（高度上限）

- 由显示器逻辑高度算浮层高度上限（纯逻辑，单测覆盖）：取显示器逻辑高度的 `HEIGHT_CAP_FRACTION`，再扣 `WORK_AREA_MARGIN`，且不低于 `OVERLAY_HEIGHT`（矮屏兜底）；请求不超过上限时原样返回。

## centered_on_monitor

- 浮层在指定显示器上居中的全局桌面坐标（winit 的窗口定位口径是跨显示器的桌面坐标，主显示器左上为原点；显示器尺寸按各自缩放比例换算）。

## clamp_to_monitor

- 把期望位置钳制进“原点在 `origin`、逻辑尺寸 `screen` 的显示器”内，以浮层尺寸 `overlay` 为界（右/下越界向内收，显示器比浮层还小时贴原点）。坐标是全局桌面坐标，与 winit 窗口定位口径一致。

## Placement（浮层摆放意图）

- 尺寸自适应变化时的重定位依据：居中者在尺寸变化后重新居中（显示入口只能按上一帧尺寸算位置）；定点者（跟随划词，或用户拖动后的落点）在原锚点上按新尺寸重新钳制，不被居中覆盖。
- `Centered`：居中显示（无划词锚点的场景）。
- `At`：定点显示：锚点是期望的浮层左上位置（全局桌面坐标；写入方钳制与否不定——跟随划词写原始释放点，拖动写钳制后的落点），读取侧一律再钳制。

## WindowManager（窗口管理器）

- 持有各窗口的生存期，对上层只暴露“谁的窗口”“显示/隐藏”。
- 字段：`overlay_size` 浮层当前逻辑尺寸（内容自适应；`centered_position` 居中计算取它）；`placement` 当前摆放意图（`set_placement` 更新，尺寸变化时按它重定位）。
- `new`：创建浮层与设置窗口。必须在 `resumed` 里调用——只有进入 resumed 才允许创建窗口与 surface。浮层是“内容即窗口”的卡片：无系统标题栏、置顶、尺寸由内容决定；透明：卡片圆角之外要让桌面透出来，因此 surface 也得选带 alpha 的合成模式。窗口创建即可见，预创建的浮层必须立刻压下去。设置窗创建即隐藏：可见前 `show_settings` 会按当前界面语言写入标题，这里的占位只在窗口从未显示过时存在；与浮层同层：同层窗口按激活序排布，聚焦即浮于浮层之上。
- `overlay`：浮层窗口本体（事件处理用）。
- `set_placement`：记录浮层的摆放意图（每次显示前设置）；尺寸自适应变化时按它重定位——居中者重新居中，定点者原锚点重新钳制。
- `set_overlay_size`：应用浮层内容的期望尺寸（内容自适应高度）：按显示器钳制高度后才重设窗口，变化小于阈值时不动——渲染帧后逐帧调用也只在真实变化时触发 resize；尺寸变化后按摆放意图重定位（显示入口只能按上一帧尺寸算位置：居中者不重定位会向下溢出屏幕，定点者不重定位会被旧尺寸的钳制结果挤离锚点）。`debounced` 为真时走流式防抖（`debounced_size`）：宽度保持当前值、高度按步长只增不减；为假（骨架/失败/完成态）按精确尺寸重排——TaskDone 的定型也走这一支。顺序：先防抖量化、再按屏幕钳制——反过来的话，量化取整会把已钳到屏高的高度又推回去（800 → 816），每帧在边界上抖动。即时生效的平台返回实际物理尺寸（可能与请求有出入），换算回逻辑值记录；异步交付的平台（Wayland）返回 None，先记请求值，随后的 Resized 事件照常驱动 surface 重建。
- `apply_overlay_drag`：页头拖动的逐帧落点：以浮层**当前实际**位置为基准，加上指针自按压点起的累计位移（窗口内相对逻辑点，egui 口径），按命中的显示器钳制后应用，并把摆放意图记为定点——锚点随拖动落点走，流式增高的重定位因此不会把窗口拽回拖动前的旧锚点。落点每帧从实际位置重算（无增量记账）：窗口中途被谁动过（流式重定位、指针随窗口移动的反馈）都被下一帧的落点自然吸收；指针未动时落点即当前位置，等于动量以下的位置变化不再下发（流式重绘帧不做无谓的平台调用）。当前位置读不到（窗口已亡等）时带痕迹降级：跳过本帧平移。
- `centered_position`：浮层居中于显示器（逻辑坐标）：优先窗口当前所在的显示器，其次主显示器。
- `clamp_position`：把浮层期望位置钳制在释放点命中的显示器范围内（跟随划词位置用）：以浮层当前尺寸为界，右/下越界时向内收；找不到命中显示器时回落浮层当前所在显示器，再拿不到就原样返回。坐标是全局桌面坐标（与 winit 窗口定位、CG 释放坐标同口径）。
- `monitor_containing`：释放点命中的显示器（按全局桌面坐标判界）；浮层当前显示器作兜底。
- `cap_height_to_screen`：高度按浮层所在显示器钳制，上限为显示器逻辑高度乘 `HEIGHT_CAP_FRACTION` 再减工作区余量（见 `capped_height`；超出部分由内容侧滚动兜底）；拿不到显示器时原样返回。
- `show_at`：reposition + show：唯一显示入口（预创建复用只显隐）。
- `hide`：隐藏但不销毁：窗口与 surface 原样保留，下次显示零重建成本。
- `is_visible`：浮层当前是否可见（winit 返回 `Option<bool>`，窗口已消失时按不可见算）。
- `handle_refcount`：浮层句柄的引用计数：唯一窗口只显隐不重建，计数应恒定不变，显隐自检用它验证无窗口泄漏。
- `overlay_handle` / `settings_handle`：共享句柄（surface 要持有窗口到 'static）。
- `show_settings`：显示设置窗口并置前（已可见则只是聚焦）；标题由调用方按当前界面语言给（`Text::app.settings_title`），草稿与文案表都由调用方管理。
- `hide_settings`：隐藏设置窗口（关闭按钮/保存完成）；窗口本体保留，渲染帧由壳层随关闭释放（见 `crate::present::workspace::drop_settings_frame`）。
- `matches_overlay` / `matches_settings`：事件是否来自浮层/设置窗口。
- `request_redraw` / `request_redraw_settings`：请求重绘浮层/设置窗口。

## 用户拖拽缩放（clamped_user_size）

- 2026-10-28 浮层新增用户拖拽缩放宽高：缩放热区在浮层界面侧逐帧上交期望尺寸（逻辑点），壳侧钳制后落窗（2026-10-29 起求解改走 `anchored_user_resize`，见下节）。钳制是纯函数 `clamped_user_size`（单测覆盖）：宽收到 `OVERLAY_MIN_WIDTH` 与 `OVERLAY_MAX_WIDTH`（再按显示器工作区宽收窄，比最小档还窄的屏保最小档），高收到 `OVERLAY_MIN_HEIGHT` 与黄金占比减余量——高度上限与内容自适应的 `capped_height` 同源：同为 `HEIGHT_CAP_FRACTION`，矮屏同样回落默认高度（首版上限回落取了最小档，短笔记本屏上占比减余量低于默认高会让用户上限低于内容上限，按住握把不动就把已到默认高的卡片往回缩——评审抓出后改回落 `OVERLAY_HEIGHT`，与内容路径逐字同源）；最小档才取 `OVERLAY_MIN_HEIGHT`——用户主动缩放允许比默认矮，滚动区兜底。
- 落窗后左上缘锚定：以当前外置位置重钳并切到 `Placement::At`——拖右下角时窗口贴着手势方向生长，不回中。位置不变且目标尺寸与当前差在 `RESIZE_EPSILON` 内的帧早退，不做无谓平台调用。
- 尺寸接管语义：期望尺寸由界面侧跨帧粘性保持（`RenderState::user_size`），拖过一次即整段会话由用户接管宽高——若仍逐帧套内容自适应高度，用户缩矮的窗口会被内容高立刻顶回去。显隐时随 `reset_drag_state` 清空，新会话回默认尺寸；尺寸随会话（不落盘）是有意为之——划词弹窗是从属旁注，持久尺寸反而让下一次弹窗带着上一次的形状。
- `request_inner_size` 的同步返回值写回 `overlay_size`（平台可能钳成别的值），与 `set_overlay_size` 同口径，后续位置钳制与拖动换算都以此为准。

## 用户缩放的锚定求解（anchored_user_resize，2026-10-29）

- 热区扩到四角与四边界后，西、北向拖动必须同时平移窗口原点——期望宽高与窗口位移合起来求解，纯函数 `anchored_user_resize`（单测覆盖）：被拖的边随指针走、对侧边（东、南）钉在按下帧的位置。求解分两步：先按意图算期望宽高并经 `clamped_user_size` 钳进设计包络，再按钳后的**实际**尺寸反推窗口原点（西拖 `x = 东锚 - 实际宽`、北拖 `y = 南锚 - 实际高`）——反推保证钳制发生时对侧边也不被拽离原地。
- 按下瞬间不跳变：界面侧上交的 `Press` 帧带按下指针，锚点记下它与被拖边的**抓取偏移**（按下点不在边的几何线上，角区可偏到 `CORNER` 14 像素）；被拖边的目标位置始终是“指针位置减抓取偏移”，指针未动时求解结果恒等于当前窗口（有测试锁定）。若无偏移修正，按在角区内侧的第一次求解会把窗口瞬移到指针处。
- 会话锚点 `UserResizeAnchor`（按下帧的位置、尺寸与全局指针）由 `begin_user_resize` 建立：窗口内指针换全局坐标要用**当前**窗口位置（帧渲染与壳侧处理之间窗口未再移动，两读一致）；此后 `apply_user_resize` 每帧以当时位置换算指针全局坐标求解落窗，`settle_user_resize` 粘性帧不落窗。落窗口径沿用：`request_inner_size` 的同步返回值写回 `overlay_size`，位置钳制回屏并切 `Placement::At`，尺寸差在 `RESIZE_EPSILON` 内的帧早退（尺寸冻结时位置由尺寸与锚点唯一决定，一并冻结）。
- 会话终止：松开的粘性帧（`settle_user_resize`）即清锚点——拖动会话随松手结束，迟到的拖动帧不再从陈旧锚点求解，新的按下帧重建锚点，与界面侧会话复位对称；`hide` 随显隐重置再清一道；`show_at`、`hide` 因此改 `&mut self`。
- 降级留痕：按下帧或拖动帧读不到窗口位置与显示器时跳过求解并告警（与页头拖动的降级口径一致）——按下失败时界面侧会话已开，静默会让整段会话既接管尺寸又不落窗。
