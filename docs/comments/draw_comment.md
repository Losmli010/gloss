# draw.rs（gloss-eval svg 子模块）决策记录

> 按符号锚定（不写行号，防漂移）。改到相关代码时同步更新本文件。

## 面板落墨的发射顺序

- 按图形元素分步——标题与内联图例、网格与 y 轴标签、frame 与 x 轴稀疏刻度、序列折线与圆点。发射顺序即字节顺序，改动任何一步都会改写渲染产物。

## PointData

- 各点的横向呈现数据：x 坐标、x 轴刻度文本与悬浮标签——三条平行数组，下标即点序，全部面板共享同一份。

## y_of

- 值 → 画布 y：值域线性映射到 frame 内（上下界按构造恒不等，无除零）。

## hover_label

- 悬浮标签：UTC 时间 + mode（+ commit）。

## x_positions

- x 坐标：首末点各内缩一格，中间均匀分布；单点居中。

## tick_indices

- x 轴稀疏刻度取样：≤4 个，均匀取（四舍五入到最近点）。

## segments

- 连续有样本的段（断线跳段不造点）。

## text_w

- 按字符宽度估算文本像素宽（CJK/全角 1em、空格 0.52em、其余 0.58em），供图例右对齐排版。
