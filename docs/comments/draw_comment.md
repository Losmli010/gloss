# draw.rs（gloss-eval trend 子模块）决策记录

> 按符号锚定（不写行号，防漂移）。改到相关代码时同步更新本文件。

## 面板落墨的发射顺序

- 按图形元素分步——小节标题与内联图例、网格与纵轴标签、外框与横轴日期
  刻度、序列折线与圆点、最新一轮的放大圆点与末值标注。发射顺序即字节顺
  序，改动任何一步都会改写渲染产物。

## PointData

- 各点的横向呈现数据：x 坐标、x 轴刻度文本与悬浮标签——三条平行数组，
  下标即点序，全部面板共享同一份。

## y_of

- 值 → 画布 y：值域线性映射到图框内（上下界按构造恒不等，无除零）。

## hover_label / run_date

- 悬浮标签：UTC 时间 + 模式（+ 提交标识）；横轴刻度文本取同源短格式的
  月日段——两处同用一个时间格式化出口，不各备一套。

## x_positions

- x 坐标：首末点各内缩一格，中间均匀分布；单点居中。

## tick_indices

- x 轴稀疏刻度取样：至多与窗口上限同数（五个），均匀取（四舍五入到最近
  点）；窗口内点数不超上限时全刻。

## segments

- 连续有样本的段（断线跳段不造点）：模型线缺该轮、延迟缺样本都不造点。

## draw_polyline / draw_end_label

- 折线发射：模型总体线以虚线绘制（派生均分与规则判定的三率在视觉上分
  家）；末值标注只落在每条序列的最新样本点上，标在放大圆点附近，上下
  侧随序列的避让位而定。

## text_w

- 按字符宽度估算文本像素宽（CJK/全角 1em、空格 0.52em、其余 0.58em），
  供图例右对齐排版。
