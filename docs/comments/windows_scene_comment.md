## 前台应用加安全输入态（2026-11-06，Windows 移植 P2①，替换同日 P0 桩）

- 前台应用：前台窗口的进程映像名——`bundle_id` 填可执行文件名（含扩展名，
  如 `1password.exe`），`name` 填映像名去扩展名的进程名。与系统（macOS）的
  语义漂移（移植方案 §2/§6 写明）：系统（macOS）的 bundle 标识是反向域名
  套标识，系统（Windows）侧这两字段都是进程名家族——敏感名单因此两平台
  各持一份（见防护模块记录），按可执行文件名逐字匹配（ASCII 大小写不
  敏感）。匹配规则（是否含路径、是否含厂商前缀）按移植方案以真机数据
  定案（L4 待办，首发按裸文件名）。
- `is_self` 按进程标识比对（与系统（macOS）同语义）。
- 安全输入态恒为关：系统（Windows）没有可查询的安全输入开关（系统（macOS）
  的 Carbon 查询无对应物）；密码框防护由敏感应用名单承担。安全桌面（UAC）
  下前台窗口查询失败返回空事实，闸门按“无事实”放行——探针读不到不该
  升级成拦截。
