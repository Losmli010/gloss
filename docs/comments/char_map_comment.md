## TRAD_SIMP_PAIRS

- 2026-10-28 数据源：开放中文转换开源项目（OpenCC）的 TSCharacters.txt（Apache-2.0 许可，<https://github.com/BYVoid/OpenCC），按设计> §9.1「字表从 OpenCC 字表裁剪为二进制常量」。裁剪口径（实施时定的开放问题，设计 §10）：只收「单字对单字且繁简字形有别」的条目，共 3152 对，按码位排序；多字词组映射（短语层繁简转换）不收——本判定只做字形层检测。数据以（繁，简）成对字符拼接的常量串入库（UTF-8 下 CJK 恒 3 字节，长度恒为偶数），运行期一次性建 `HashMap<char, char>`（OnceLock），查询摊还 O(1)。
- 2026-10-28 形态选择：常量串 + 运行期建表，而不是排序数组 + 二分或编译期生成 match——建表一次性成本微秒级，代码量最小；字表更新 = 重跑生成脚本换串，无逻辑改动。
