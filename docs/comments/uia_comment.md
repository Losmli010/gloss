## selected_text（2026-11-06，Windows 移植 P2①）

- 焦点元素的文本模式（TextPattern）选区读取：`GetFocusedElement` →
  `GetCurrentPattern(UIA_TextPatternId)` → `GetSelection` → 首个范围
  `GetText`。是向目标应用发起的同步跨进程调用，必须运行在套间初始化过的
  平台事件线程（线程约束由事件线程启动序承载，见组件对象模型记录）。
- 错误面收成错误码（`HRESULT` 整值）：文本模式缺席（自绘应用不支持）与
  调用失败都上抛，由读取器统一映射为读取不可用——组合通道落剪贴板兜底。
- 无选中范围（数组空）与空串都返回空串——两者都是“属性在而无选区”，按
  空选区语义上抛（组合通道先让渡补读）；范围取首个——多范围选择（不连续
  选区）取首段与系统（macOS）只读选中文本属性的语义一致。
- 超上限不取全文：文本字节量超过上限时返回空值，调用方按读取不可用处理
  （与系统（macOS）读取器的超限语义同构）；上限常量在读取器模块。
- `UIA_TEXT_PATTERN_UNSUPPORTED`：文本模式缺席的自造标记码（负值，系统
  `HRESULT` 正常码不会取到），读取器的映射据此与调用失败同路。
