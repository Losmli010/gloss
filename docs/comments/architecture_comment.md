## core_forbidden（前缀匹配）

- 2026-09-18 用前缀匹配覆盖同族新包（wgpu-core / egui-wgpu / objc2-app-kit …），免得每次出新包都要补名单。红线范围：平台、渲染与系统适配栈（窗口库、图形后端、界面库、平台桥、剪贴板、字体、输入模拟、热键、目录服务等）。

## 包名登记护栏

- 2026-10-25 包名必须在项目文档（AGENTS.md）里出现过：约束表与依赖边是两处维护，靠这条挡住单边改动；项目文档缺失时整段跳过（不误报）。

## 约束「评测资产隔离」（实现）

- 评测包（gloss-eval）是评测工具链，依赖方向断言已保证它只消费、不被依赖；这里再钉两条硬边界，防评测资产从旁路渗进生产：
  - 一、评测包之外的清单不得出现对它的依赖（即使边表将来被误放宽，这条仍然挡住）；
  - 二、评测包之外的源码不得用内嵌宏（include_str! / include_bytes!）引用评测资产。扫描面是各包源码、根源码、测试与基准目录，评测包自身目录除外。

## 通过行的条件语义

- 依赖方向一行无条件输出（含边数与登记确认）；评测资产隔离一行只在依赖引用与内嵌引用双零时输出——有违规时该行缺席，与拆包前一致。

## 反馈迁移（2026-10-25，PR2c）

- 五条判罚各挂规则标识：非法边、核心库红线、包名未登记、评测包被依赖、评测资产内嵌；判罚消息去掉「constraint violation (xxx)」前缀——标识承担分组语义，领域词并入消息正文。
- 证据行完整不截断：依赖方向与红线带完整条目全文，评测资产内嵌带完整违规行；证据截断（旧取前六十字符）与单文件报告上限（超限声明剩余数）由共享层报告器统一收口。
- 评测资产内嵌的取证从「行清单取首条」改为带行号枚举取首条：证据行进统一诊断出口需要行号，判定口径不变（仍每文件一条）。
- 包名未登记的违规条目行号取零（文档比对判罚不落在清单的具体行）。
