## 结构层三判罚（PR-T3，2026-10-26）

- 三条判罚（标题跳级、同文档重名标题、结尾围栏不闭合）的判定落在语言规范库的文档
  结构遍历入口，本模块把逐行与结构两个入口的结果拼接返回；标识前缀
  `COMMENT-DOC-`，登记行见门禁规则标识登记表（`gate_rules_comment.md`）。
- 作用域只到文档子门禁：逐行遍历入口同时被提交信息与拉取请求内容门禁复用，结构判
  罚若挂在那条共用路径上会把提交信息与拉取请求正文也纳入结构受检——超出手册附录 B
  与重构方案第四节给本判罚划定的「随 comments 配方生效」范围，也超出基线清扫覆盖的
  六份受检文档，故单独成第三个入口、只由本模块拼接。
- 重名判定用标题文本逐字相同（剥首尾空白），不做去注记归一：受检文档里同键标题靠
  全角括号注记区分是正当写法（如测试行为清单的同名条目带不同日期注记），归一后会把
  它们误判成重名。
- 围栏开合翻位与逐行遍历保持同一口径（剥首尾空白后以三反引号起行即翻位），结尾围栏
  不闭合按开启行报位置；既有翻位行为一字未动，只把「文末仍开启」从静默放行改为判罚。
- 基线：六份受检文档（自述、指令文档、安全政策、拉取请求模板、图标说明、测试行为
  清单）在开门禁前扫描为三类零违规，本拉取请求无存量清扫差异。

## 结构三罚移交排版工具（2026-10-26）

- 三条结构判罚（标题跳级、同文档重名标题、结尾围栏不闭合）整体移交排版门禁工具
  （rumdl）：对应规则为标题递进、重名标题与未闭合围栏检测（rumdl 的规则编号
  `MD001`/`MD024`/`MD046`），围栏不闭合在工具侧可自动修复（补闭合行）。移交后
  本模块只做逐行书写纪律判定，语言规范库的文档结构遍历入口随迁出删除，三个
  规则标识同步退出登记表（gate_rules_comment.md）。
- 移交动机：结构与排版规则与格式化工具的判定高度重叠，工具侧还能自动修复；
  自有判罚只剩维护两套口径的成本。工具经 `fmt-md`/`lint-md` 配方进提交前门禁
  与持续集成，受检面（版本库跟踪的标记语言文档）比本门禁宽——提示词目录作为
  模型资产也进排版面（用户决策，评测回放按用例编号匹配夹具、不按提示词内容
  做键，格式化不破坏评测轨）。
- 历史条目（上方「结构层三判罚」）保留作沿革：其时判定与豁免口径已随移交失效，
  现行口径以 rumdl 配置（rumdl.toml）与其记录文件为准。
