# check_review_result.py 注释记录

- 调用方：hooks.yml 的 review-result 作业（pull_request_review 的提交与编辑事件，
  正文取自托管平台接口），以及客户端钩子 check_pr_title.py 的评审路由。
- 骨架小节、声明正则、小节块提取与模板读取复用 check_review_template.py 的同一批
  单点——模板文件门禁与本门禁共用，两处判定不会漂移；正文模板缺失按无法完成判定
  处置（失败关闭），与模板文件门禁同口径。
- 书写规则复用语言规范库的标记语言遍历，标识沿用登记表内的书写规则九标识，不另设。
- 只拦评审（pull_request_review 与 `gh pr review`），不拦普通评论：评审结果模板的
  判定与托管平台的评审动作一一对应，评审结果是评审人的正式产物；评论是日常讨论，
  全拦会误伤。取舍记于 check_pr_title.py 记录同节。
- 空正文不进判定面：作业条件在事件层挡空正文、撤销与机器人评审；命令行直接跑时
  空正文按缺骨架与缺声明拦。
- 短旗标连写（-b评审正文）按外壳与托管平台命令行的真实解析形态处理，等号与连写
  等价；测试夹具正文按书写规则白名单组句，防夹具自身误触判罚。
