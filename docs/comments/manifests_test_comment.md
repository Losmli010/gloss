## 为什么逐条锁读取语义

- 2026-10-25 缓存的价值前提是“经缓存的读取与自行打开文件逐字节一致”：换行翻译（回车换行与孤立回车折成换行）、容错口径（严格抛错与替换字符）、缺文件照常抛操作系统错误——最后一条正是“读不到即报违规”路径的单元级锚点，缓存不得吞错、也不得缓存失败。
- “同一文件一次扫描只打开一次”是性能交付的契约而非实现细节，用包裹内置打开函数计数断言：两次读取只发生一次真实打开、内容一致。容错口径进缓存键（同路径不同口径各存一份）由恒等断言锁定。
- 清单枚举与跟踪清单的共享断言用恒等（同一列表对象）：后续任何把缓存改成逐次新建的回退都会当场变红。
- 共享夹具助手建一次性版本库后返回缓存实例；跟踪清单的枚举形态（空字节分隔、排序结果）与并轨装入器的同名单测同形，两边口径漂移会有一侧变红。
