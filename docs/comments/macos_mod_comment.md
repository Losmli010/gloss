## 目录定位（2026-11-05，Windows 移植 P0 §3.1）

- 现有全部模块整体迁入 `macos/`，子模块结构与迁移前的库根一致：代码内容零改动（`git mv` 保历史），系统框架（AppKit/CoreFoundation）的线程约束与 FFI 收口规则原样随迁。
- 子模块在本文件集中声明；`ffi` 保持包内可见（`pub(crate)`），由入口（lib.rs）重新导出为 `crate::ffi`——迁入文件内的 `crate::ffi::…` 引用因此一字不改。
- 入口按目标把本目录的子模块重新导出为平台无关路径，消费方 import 面不随编译目标变化；本目录自身不再被直接引用。
