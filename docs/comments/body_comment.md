- 2026-10-28 正文范围：数学定界区（含定界符）与容器内容区全部掩掉，容器定界符留在正文——定界符要参与 R2 豁免（目标标点集内或按定界符豁免）与 R4 的标点隔断语义（」2023 不判缺空格）。
