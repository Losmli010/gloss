## 绑定面（2026-11-14，方案 A6）

- 本模块只剩绑定：用户界面自动化（UIA）读取器与剪贴板兜底读取器接上共
  享组合通道的读取装配（`acquire`）；组合判定、让渡节奏与读等待预算随共
  享层单源，本模块不再持有时序数字。
- 激活闸门缺省：系统（Windows）没有需要唤醒的无障碍树（Chromium 系宿主
  的无障碍树默认建树），文本模式缺席时等再久也读不到，注入才是解法；让
  渡耗尽与“读不到”直接落兜底（`wake` 传空）。
- 权限语义缺省：无闸门形态没有权限拒绝分支——共享判定对
  `AccessibilityDenied` 照常落兜底（本平台的读取器本就不产出该错误），行
  为与迁移前逐字一致，锁定测试见共享层记录。

## 符号契约

- `CompositeReader`：选区读取的组合实现：用户界面自动化（UIA）文本模式
  优先，读不到降级剪贴板兜底（模拟复制）。取材轮次闩锁句柄传给兜底通道。
  - `new`：创建组合读取器：传入与哨兵源共享的取材轮次闩锁句柄。
  - `read`（文本取材端口实现）：读取前台应用的选中文本；产物与收尾分离，
    兜底轮的恢复写盘经 `TextSettle::finish` 随产物上抛之后执行——恢复不
    挡在产物交付前；产物已修剪两端空白。调用方保证：在平台事件线程上调
    用（收尾同线程）。
