# trend.rs（gloss-eval）决策记录

> 按符号锚定（不写行号，防漂移）。改到相关代码时同步更新本文件。

## TREND_MAX_RUNS

- 趋势图最多绘制的迭代运行数：只画最近五轮（JSONL 本身不裁剪）；横轴
  刻度上限随窗口放宽到五根——窗口内全部刻出。

## render_svg

- 曲线渲染唯一出口：检视页历史区块与 `eval history` 命令行共用本入口，
  序列清单只有一份（契约有效率、回归通过率、标注合格率、模型总体均分、
  中位延迟、95 分位延迟），检视页与命令行产物不得各绘一套。
- 确定性渲染：面板数随数据条件变化（延迟面仅历史有样本才画、模型线仅
  历史有已评轮次才画），输出无渲染时刻的时间戳，同输入逐字节一致。
- 2026-11-01 评测工具链重构步骤 5：由 `svg.rs` 改名而来，序列清单重建——
  步骤 1 曾随轨删除旧面板只留延迟分位，本步按重构计划恢复三率与模型总
  体，窗口由最近 100 点改为近五次迭代运行。

## COLOR_GREEN / COLOR_AMBER / COLOR_RED / COLOR_GRAY / COLOR_TEXT / COLOR_MUTED

- 徽标与曲线共用色的单一定义点：曲线用色与检视页徽标四色同源，检视页
  样式经占位符注入此处色值；中灰兼作模型总体线与徽标文字灰。

## latest_runs

- 只取 `iterate` 模式的运行并裁到最近 `TREND_MAX_RUNS` 轮：其他模式即便
  能解析成新形状也不进图、不进标注。

## write_header / latest_note / svg_height

- 画布头部：svg 开标签、白底、标题行（轮数）与右上角“最近一轮”标注；
  无面板时以“暂无评测历史”占位文案替代图面。
- “最近一轮”标注：UTC 时间加模式与提交标识（如有）；旧英文口径脚注随
  序列重建删除。

## esc / f2 / line

- 文本节点经（XML）实体转义，浮点坐标固定两位小数，行发射统一出口。
