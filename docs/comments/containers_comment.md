## scan_containers

- 2026-10-28 单趟栈式扫描：括号组（按目标括号对，可嵌套）、弯引号组（按字形配对）与直引号组共栈处理——父子关系在出栈时记为「父组的开定界符下标」（`parent_open`），`direct_ranges` 据此把子组整段从父组直接内容里剔除（R8「内层括号组递归单独判定」）。
- 2026-10-28 直引号不真嵌套：栈顶是直引号组才闭合，否则当新开组——与「按出现次数两两配对」在常见形态等价；直引号与弯引号交错的病态串行为任意但确定，宁漏勿误不另设规则。
- 2026-10-28 游离闭合符（无对应的 `）` `”`）记残缺（`unclosed`），与未闭合开符合并成字段级一条 `UnclosedContainer`（违约按字段×类别去重，天然合并）。
- 2026-10-28 数学定界区先切：容器扫描跳过数学区（掩码入参）——数学容器最优先，内部括号引号不作容器（设计 1.2 切分顺序）。
- 2026-10-28 代码任务不开引文容器（设计 §2 表格「—」）：引文字符按普通标点判，内容按正文判；其余四任务引文容器开启。
