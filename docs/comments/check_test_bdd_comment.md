## 唯一性三道补齐（2026-10-27）

- 集合差集抓不到的三类缺口由新三检查闭合：登记行数对账源码跨文件实例数（`BDD-INSTANCE`）、跨文件同名必须带文件绑定限定符（`BDD-BINDING`，限定符＝定义文件名主干，mod 文件取父目录名）、同条目两行绑到同一文件（`BDD-DUP-QUALIFIER`）。实例从名字集合升级为“名字 → 定义文件集合”，测试目标按 tests/ 目录同名文件解析实例，声明缺席文件仍进双向核对但不进绑定。

- 测试源码跟踪清单枚举收口为一次全量枚举（语言源码过滤与登记文件枚举共用），装入器在场走共享缓存，单独运行走统一诊断出口的 git 包装，失败关闭语义不变。
