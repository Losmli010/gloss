## 命名与同源机制

- 命名规则：大写字母加短横线（可含数字），前缀按脚本域——约束、密钥、文档引用、行为清单、文案表、提交信息、拉取请求、注释、通用。
- 住处两处同源：常量定义随 gate_report.py（通用域三标识）或各脚本常量区（密钥域三标识在 check_secrets.py，其余域随各自迁移 PR 落进对应脚本），代码引用只能取自登记处；各标识的含义、判罚口径与豁免方式住本文件，不进源码文件头（注释纪律禁止文件头罗列条目）。
- 代码侧权威清单是 gate_report.py 的 REGISTERED_RULES——本文件随记录目录入库，持续集成在场，登记表同步测试（gate_report_test.py）核对两边集合与全部调用点。
- 一致性测试的静态扫描口径：常量定义按「RULE_ 前缀名 = "标识"」整行匹配，行尾允许跟放行标记注释；违规条目的规则实参按「rule=大写常量名」或「rule="标识字面量"」匹配——字面量直接核对登记清单，常量先核对定义再核对登记清单；位置传参不被扫描覆盖，防漂移靠常量定义侧核对兜底。
- 新增标识的动作：先在本表补行（含义、判罚口径、豁免方式），再在对应脚本常量区或 gate_report.py 定义常量并落进 REGISTERED_RULES——两处缺一即被一致性测试拦下。
