## 桌面快捷方式写入（2026-11-10，Windows 移植 P3b 后续）

- 外壳链接对象经组件对象模型（COM）类厂创建、填目标与图标后经持久化文件接口（IPersistFile）落盘；目标与图标都取可执行文件自身（图标随资源段嵌入，见构建脚本记录）。
- 套间按需补初始化并成对卸载：调用点在界面主线程的启动装配段，窗口库装配后线程已是单线程套间（补初始化回已初始化），静默变体不落日志——失败语境由调用方陈述。
- 桌面目录走已知目录接口（SHGetKnownFolderPath），系统分配的内存转换即还；路径按有损转写进宽串（Windows 路径本为宽字符，实际无损）。
