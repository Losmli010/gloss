# overview 决策记录

> 本文件随仓库跟踪（docs/comments/ 入库），改名与合并用 git mv 保留历史；文件内不留指向本文件的指针。

## render

- 指标总览两段：柱状图先行（每类型一组竖柱，契约有效、回归通过、标注
  合格三项合格率与模型均分各一柱，均 0–100 直读），单数字指标表随后，
  合计行收尾；全部单元格只读报告分组聚合，视图层零重算。

## ordered_groups

- 展示顺序固定为分类、词卡、句译、代码、通用（计划的五键次序），缺席
  类型不画组；聚合键中出现清单外名称（如预留给图像的类型）时按字典序
  追加在五键之后，合计恒收尾——聚合层键序是字典序，展示层不照抄。

## bar

- 柱高按 0–100 线性映射（100 对应 80 像素），0 画短桩（2 像素）、无数
  据不画柱只落占位符；模型柱用中灰以示派生均值，悬停标注口径——三项
  合格率带百分号，模型均分为裸分数。

## table_row / dims_note

- 每格只放一个数字，明细进悬停：三率悬停带各自的状态计数，模型格悬停
  带四维均分，评审覆盖悬停带已评数与例数，基线格悬停带基线数、标注数
  与基线固化时间（取组内最新一条 `accepted_at`，资产映射按类型归并，
  展示口径见计划 §七）。
- 质量聚合置空（评审关闭或组内全为分类用例）时，模型、四维、评审覆盖、
  人机一致七格一律占位符——效果图曾对分类组显示 0% 覆盖，但报告层无法
  区分“零覆盖”与“不适用”，状态矩阵（`--no-judge` 行）要求占位符，故统
  一占位；人机一致率的可比分母未入聚合模型，悬停不造数。
