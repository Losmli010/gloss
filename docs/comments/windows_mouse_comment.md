## 手势源（2026-11-06，Windows 移植 P2①，替换同日 P0 桩）

- 判定逻辑与系统（macOS）同构：拖拽释放（按压时长与位移双达标）滤瞬时
  甩动与普通点击，订阅面只有左键按下与释放。两处参数按系统（Windows）
  的事件时刻口径换算：按压时长下限一百五十毫秒（事件时刻来自
  `MSLLHOOKSTRUCT.time`，毫秒粒度），位移阈值复用十二个屏幕单位——系统
  （Windows）坐标是物理像素（进程的每显示器（DPI）感知档影响取值），
  系统是（macOS）点坐标，同一数值在不同缩放档的手感差异待真机校准（L4）。
- 线程模型：监听在独立线程（`gloss-mouse-tap`，与系统（macOS）同命名口径）
  建立并跑消息泵宿主（低级钩子的回调在安装线程取送消息时被系统调用），
  产物经有界通道（二百五十六格，满则丢弃）汇入平台事件线程的轮询侧——
  钩子回调内只做坐标判定并入队（AGENTS.md“回调只搬运”约束），手势判定
  不在回调里。无停止接口，监听线程随进程退出消亡；泵退出经标志异步置位
  （`mouse_degraded` 既有通路），建立结果同步握手（与系统（macOS）同形）。
- 与系统（macOS）的差异：低级钩子无需系统授权，创建失败路径实际只剩系统
  资源失败；回调经线程局部槽取队列发送端（低级钩子回调没有用户数据参数，
  回调保证跑在安装线程）。
- 键盘事件不进入本模块：只按消息号收左键按下与释放，其余消息原样交回
  钩子链（`code < 0` 必须直接交回，是低级钩子契约）。
- 2026-11-06（P1 合入后适配）实现核心层选区手势源端口（轮询直出屏幕点
  坐标，事件源镜像 `EventSource<MouseGesture>` 与手势枚举随之退役——端口
  是共享契约，事件线程侧的转译归装配段）。
