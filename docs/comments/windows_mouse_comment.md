## 手势源沿革（2026-11-06，Windows 移植 P2①，替换同日 P0 桩）

- 判定逻辑与系统（macOS）同构（现随共享层单源）：拖拽释放（按压时长与
  位移双达标）滤瞬时甩动与普通点击，订阅面只有左键按下与释放。事件时刻
  口径：`MSLLHOOKSTRUCT.time`，毫秒粒度（现于钩子回调里换算为
  `Duration`）；位移阈值复用十二个屏幕单位——系统（Windows）坐标是物理
  像素（进程的每显示器（DPI）感知档影响取值），系统是（macOS）点坐标，
  同一数值在不同缩放档的手感差异待真机校准（L4）。
- 线程模型：监听在独立线程（`gloss-mouse-tap`，与系统（macOS）同命名
  口径）建立并跑消息泵宿主（低级钩子的回调在安装线程取送消息时被系统
  调用），产物经有界通道（容量随共享层单源，满则丢弃）汇入平台事件线程
  的轮询侧——钩子回调内只做事件搬运（AGENTS.md“回调只搬运”约束），
  手势判定不在回调里。无停止接口，监听线程随进程退出消亡；泵退出经标志
  异步置位（`mouse_degraded` 既有通路），建立结果同步握手（与系统
  （macOS）同形）。
- 与系统（macOS）的差异：低级钩子无需系统授权，创建失败路径实际只剩系统
  资源失败（`ListenError::Hook`）；回调经线程局部槽取队列发送端（低级钩
  子回调没有用户数据参数，回调保证跑在安装线程）。
- 键盘事件不进入本模块：只按消息号收左键按下与释放，其余消息原样交回
  钩子链（`code < 0` 必须直接交回，是低级钩子契约）。
- 2026-11-06（P1 合入后适配）实现核心层选区手势源端口（轮询直出屏幕点
  坐标，事件源镜像 `EventSource<MouseGesture>` 与手势枚举随之退役——端口
  是共享契约，事件线程侧的转译归装配段）。
- 2026-11-14 端口实现随共享层（轮询直出屏幕点），本侧只留绑定。
