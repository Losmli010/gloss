# setup_dev.py 决策记录

> 按符号锚定（不写行号，防漂移）。改到相关段落时同步更新本文件。
> 本文件随仓库跟踪（docs/comments/ 入库），文件内不留指向本文件的指针。

## 设计原则

- 2026-09-18 硬失败只留给“没有 Rust 什么都干不了”这一件事；其余缺失只提示安装命令，不替用户做全局安装。
- 2026-10-25 修订：硬失败名单第二条是密钥门禁引擎（见下），第三条是门禁解释器（见下）——两者都是“每提交必跑、缺了门禁只能当场失败”的硬依赖，与首条同一档。
- 2026-10-25 版本比对全部改为单点读取：本语言（Rust）频道解析原生钉版本文件（`rust-toolchain.toml`），其余工具读仓库根版本清单（`tools.toml`，经 `scripts/dev/tool_version.py` 的 `parse_sections`），脚本内不再持有任何版本常量。

## Rust 工具链频道（`toolchain_channel`）

- 2026-10-25 取代原 `EXPECTED_TOOLCHAIN` 常量：双源（常量对工具链文件）从构造上消除；工具链文件是唯一权威，工作流同步去掉显式版本改 `rustup toolchain install` 按文件解析。
- 解析失败（文件缺失或无频道行）只告警跳过比对，不硬失败——工具链文件是跟踪文件，异常属仓库损坏，会在门禁层先暴露。

## 工具链版本比对（变量花括号）

- 2026-09-18 变量名后紧跟全角字符时必须加花括号：bash 3.2 会把全角字符首字节吞进变量名（报 unbound variable），本机实测踩过的坑。

## 组件存在性探测

- 2026-09-18 用命令探测而非 rustup component list 的原因：仓库用目录级 pin 时，不带 --toolchain 的 rustup 查的是默认工具链，会误报缺组件。

## 门禁解释器下限（`find_interpreter`）

- 2026-10-25 下限值来自版本清单的 `min`（现为 3.12）。主名 `python3` 可能低于下限（本机系统 3.8 即是）：按下限取同名解释器（`python3.12`）作后备候选，任一满足即过——清单记录的是“环境须存在满足下限的解释器”，不是“主名必须满足”，故本机全绿。两个候选都不满足时按缺件告警并给安装指引，仍不硬失败。
- 2026-10-25（PR-P2）`find_interpreter` 删除，改为单候选校验：任务配方的解释器入口已翻到 `python3.12`（与下限同名，见 justfile_comment.md），校验对象就是配方实际调用的那个解释器——入口名按下限派生（`python` 加下限值），脚本内不出现第二处版本字面量；缺名或低于下限当场硬失败并给安装指引（原先的告警放行会让用户在第一次跑配方时撞上更晦涩的“命令不存在”）。下限值读不到（清单损坏）仍只告警，与工具链频道解析失败的口径一致。

## 可选工具清点

- 2026-09-18 各工具只做存在性检查：具体版本交给 Dependabot 与 CI 兜底。
- 2026-10-25 修订：钉全版本的工具（ruff、tombi）升级为“在场且全等”——版本读版本清单，不一致时告警并给对齐命令（对齐命令按清单值拼装，脚本里不出现版本字面量）。tombi 提示只给 `npm i -g tombi@<钉版本>` 一条路：brew 装的是最新浮动版，与钉版本矛盾，不再并列。
- 显式浮动的条目（just、pytest）维持只看在场，不比对版本——浮动缘由记在版本清单各条目注释。
- 2026-10-06 新增 cargo-flamegraph/inferno 一条（探测 `inferno-flamegraph`，提示一次装齐 flamegraph/inferno/rustfilt 三个包）：`just flame` 的 inferno 链缺了当场报缺，setup 清点是提前一步的同一指引；探测键取 inferno 而非 cargo-flamegraph 本体，因为 attach 模式的硬依赖是 inferno 两个二进制，launch 模式的 cargo-flamegraph 缺失时 cargo 会自报 no such subcommand。

## 密钥门禁引擎校验（`check_pinned` 前的硬失败）

- 2026-10-25 硬失败名单破例新增第二条：密钥门禁每提交必跑，引擎缺失时门禁只能当场失败（降级须有痕迹），环境初始化若只告警，用户会在第一次提交时才撞上更晦涩的报错——校验挡在最前面把安装指引提前。
- 版本不一致仍走对齐建议不硬失败：判定一致由持续集成钉版本兜底，本地告警提示重对齐（与 ruff／tombi 同档）。
- 安装指引只给按钉版本装的一条命令：包管理器通用源给的是浮动最新版，与钉版本矛盾。

## rumdl 校验（2026-10-26）

- 新增 rumdl 一条（钉全版本，与 ruff/tombi 同档告警不对齐硬失败）：排版门禁经
  text-gates 组合进提交钩子，缺了提交钩子会挂，清点提前一步给指引。
- 安装提示给 uv 工具渠一条（或 pip 兜底）：PyPI 包内含原生二进制，与 CI 的
  pip 安装同源，避免包管理器浮动版与钉版本矛盾。
