## 分包落位（2026-11-18，架构重构方案 §2.3 C3 / K5）

- 本包是方案唯一的新生产分包：大语言模型（LLM）传输适配器实现核心层引擎端口
  （AiEngine），把传输协议（HTTP）客户端（reqwest 经安全传输库（rustls）引入的带
  C 代码加密库（ring））与异步运行时的看门狗/退避从纯逻辑核心库剥离——内存检查
  （Miri）不再整组跳过传输面，系统（Windows）目标可本机交叉检查。
- 依赖随迁移走：reqwest（特性集原样保留，json 特性随原依赖面——请求体已预序列化
  不取其方法面）、bytes（传输字节块）、base64（图像部件编码）、futures-core（流
  trait）；tokio 生产面只留时间特性（空闲看门狗与重试退避）。
- 开发依赖：异步测试宏与虚拟时钟（test-util），futures 供按路径属性并入的共享测试
  桩库（源在核心库 tests/stubs/，K5 定案的单源消费）。
