## 测试目标与层

- 第一层（L1）：进程映像名提取的纯函数（路径末段、去最后一个扩展名、空
  段拒绝）；探针快照的连贯性断言为进程内真实查询（纯查询面，无授权前置）。

## 辅助契约

- 正反斜杠路径、无扩展名、多点文件名都有确定映像名；裸目录路径取不到名
  （返回空，闸门按无事实放行）。
- 安全输入态恒为关（本平台无查询面）；报告出的前台应用至少带一个可用
  标识。
