## 目录定位（2026-11-14，架构重构 A3 起）

- 平台中立共享层（`common`）：两侧平台目录零差异的业务逻辑宿主目录，随系统（macOS）与系统（Windows）目标编译（`any` 门控，系统（Linux）占位目标不见它，无未使用告警）。条目按问题域分文件，当前只有配置存储（storage）。
- 本目录零目标条件编译、零外部函数接口（FFI）、零不安全块（方案定案 K3）：平台差异只经注入闭包与类型参数进入，原语与密钥半边绑定留在各平台目录；公开为 `gloss_platform::common`，供平台目录绑定共享形状（组合体的类型别名需要公开可名）。
- 时序与预算常量随各自的共享模块单源，不设集中常量模块（方案 §3.2）。
