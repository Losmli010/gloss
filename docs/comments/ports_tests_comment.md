## 桩设计契约

- 桩只承担两件事：预置返回值与可注入的失败——注入点要能造出想测的时序，观测点要能证明它发生过。
- sample_request / outcome：构造合法 EngineRequest 与 TaskOutcome 的夹具助手（桩不读请求内容，只为满足端口签名）。
