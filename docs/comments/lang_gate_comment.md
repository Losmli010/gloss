## 判定口径（宁漏勿误的具体落点）

- 2026-10-28 文字段阈值：非目标文字段连续长度 ≥2 才判 `ForeignRun`；长度 1 放行（数学变量/符号可能成段）。例外：单拉丁字母紧跟句点（`n.` 词性缩写）判罚——设计 §4 与 §8 两处明确要求。
- 2026-10-28 货币守卫：`$` 紧跟半角数字按货币符号处理，不作为数学定界符——设计 §4 明确 `$5` 是合法数字单元；这同时避免「$5 与 $10」被贪心配对成数学容器后把中间中文吞进豁免区的大面积漏报。
- 2026-10-28 数学配对约束：同类型（`$$` 对 `$$`、`$` 对 `$`）且同一文本节点内才配对（设计 1.2「跨节点不拼装」）；落单定界符留在正文且不判标点（`$` 恒豁免）。
- 2026-10-28 括号对按目标语言：中文只认全角（），西文只认半角 ( )，日语/韩语/自定义两者皆收（各对自配对）。半角括号在中文正文是标点串味（不在中文标点集）而非容器。
- 2026-10-28 日/韩/自定义标点集：设计只定义中西两集，本实现取并集从宽（R1 已抓文字系统错误，标点层从宽符合决策 7 宁漏勿误）；日语另收长音符与中点。
- 2026-10-28 直引号容器：与弯引号同走一个栈（栈顶直引号即闭合，否则开新组）——等价于按出现次数两两配对，不额外嵌套；弯引号与括号正常嵌套。
- 2026-10-28 R8 混语排除集：长度 1 的文字段（任意文字系统）都不计入，比设计「单字母变量不计入」略宽——单一希腊/假名字符夹在目标语中的混语价值极低，宁漏勿误；数字与附随符号天然不在文字段里。
- 2026-10-28 R10 比对口径：设计要求「连续空白折叠为单空格」且括注补空格不得使重合失效——纯折叠满足后者（补一个空格折叠后与无空格原文仍不相等）。实现取双口径：字符口径全文去空白比对（补空格不失效），词项口径按折叠文本比对（西文 6 词阈值需要词界）；两口径共享阈值语义，且折叠匹配集是去空白匹配集的子集，不引入额外误报。
- 2026-10-28 R10 词定义：西文词 = 非中日韩字母的连续字母数字段（设计「西文词」）；纯中文输入因此无词项 gram，只有字符口径生效。
- 2026-10-28 盘古之白的「相邻处不是标点」：实现为汉字侧行只认汉字字形（CJK 统一表意区），标点（」）。，等）天然不触发相邻判罚——直连定义下两个相邻字符就是边界，无需额外排除。
- 2026-10-28 结构节点判定用（pulldown-cmark）默认选项（不含表格/删除线扩展）：设计 §7.5 列举的全量语法（标题、清单、强调、行内码、围栏、链接）默认选项全覆盖；表格与删除线不在设计的列举内，落到正文按普通标点/文字判。
- 2026-10-28 URL 豁免的实现：链接目的地在事件流的 Tag 里（不进文本节点序列）天然豁免；自动链接（`<https://…>`）的文本与目的地相同，按链接深度剔除。行内码与围栏内容按容器豁免剔除。
- 2026-10-28 围栏与行内码闭合（全量任务）：按原始文本行统计 ``` 行数与剔除围栏行后的反引号总数，任一奇数判 `UnclosedContainer`——事件流无法区分未闭合围栏（pulldown 到 EOF 自动闭合），行计数是等价的近似（宁漏勿误：波浪线围栏不判）。
