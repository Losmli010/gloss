## 参数化分诊入口（2026-11-03，判罚面收敛一期）

- 三刀短路加区核心收成单一入口：注释块（check_script_comments 的 flush）、模块级文件头、
  函数级文档字符串（二期纳管）与文案表词条四处共用同一形状与短路链——反引号、章节引
  用两刀各自返回单例条目即返回，不再跑核心判据；中文区语言刀（剥离后无汉字）之后落中
  文区核心（body_problems），英文区无独立语言刀、直接落英文区核心（english_zone_problems）。
  重接线由既有单测锁定行为零变化（注释门禁全量用例逐字断言条目形态）。
- 面参数（TriageFace）只装规则标识、消息与修复指引，不带判罚逻辑——判据单源住语言规范
  库，各面只换装；字段不给缺省值，面装错（漏配刀 3 或英文指引）在构造处即失败，不静默
  产出空标识条目。
- 迁移范式（改写存量时）：先清反引号与章节引用，刀 1、2 短路解除后字符级病灶才会在核
  心判据下显形——一次改写分两批看罚，避免改完反引号又撞出成批字符级条目误判为门禁回退。
- 已知取舍：证据行取整段压平换行，与既有的注释块与文件头形态一致；词条面传入的是剥离
  记号后的文本，证据随之显示剥离后形态（定位以路径加行号为准，不靠证据回搜原文）。
