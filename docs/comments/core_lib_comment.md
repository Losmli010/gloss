## 目录分组与路径镜像（阶段 1，2026-10-30）

- 决策：核心库源码按实测依赖分层分三组——领域词汇与校验（domain/）、任务智能层（pipeline/，含引擎与语言门两个同名子目录整体随迁）、端口契约（contract/）；日志横切设施留顶层。分组是纯移动，模块内容零改动（仅三个文件的资产装入相对路径随落点深一层）。
- 兼容形态：库入口按分组声明四个模块，再逐项转出既有公开路径（pub 模块原样转出，原私有的措辞、修复、简报与语言规范按包内可见转出）——下游四包与基准的 use 语句与清单零改动。镜像即过渡（计划 D7）：评审与本仓文档自阶段 1 起一律写新路径，镜像清理归图像里程碑首个提交。
- 分组根文件取 mod.rs 形态（与界面层目录模块同规），避免主文件式命名与运行时管线模块撞名（登记表消歧的代价更重）。
