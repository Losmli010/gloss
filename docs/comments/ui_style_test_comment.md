## 验收意图

四条边界各自的判罚与放行两路都有用例钉住：域外色构造、解析点外明暗
直读、属主外字体构造、样式层外数值常数必须拦下；属主文件自身、带缘由
的 `style:allow`、内联测试模块与档位算术必须放行。白名单文件（图标
栅格化几何、语言资产表）的数值常数放行，是登记表契约的锁定用例；缺
缘由的放行标记单独一例，钉住标记判定助手在本域的接线。
