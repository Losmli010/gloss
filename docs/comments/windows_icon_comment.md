## MacAppIcon 镜像桩（2026-11-05，Windows 移植 P0）

- 同名镜像端口类型 `MacAppIcon`（实现 `AppIcon`）：命名沿用 macOS 侧是过渡——P1 装配收敛（D3）后消费方经 `Platform` 句柄取端口，类型名将随 P2 真实现一并正名（Windows 无对应概念，实作为无操作或任务栏覆盖）。

## 正名与无操作落地（2026-11-07，Windows 移植 P2④）

- 类型随两端口适配器统一正名 `SystemAppIcon`（与 `SystemMenuController` 等既有 `SystemXxx` 惯例一致），装配契约里平台无关的构造点不再叫 macOS 侧名字。
- `install` 实作无操作（恒成功）：任务栏与开始菜单图标在打包期由可执行文件资源承担（`.ico`，分发打包 P3 落地），运行期没有要补装的东西；恒成功使调用方启动序不因平台差异走失败分支，坞图标字节照常注入但被忽略。
