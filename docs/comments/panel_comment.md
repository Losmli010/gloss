# panel.rs（gloss-eval svg 子模块）决策记录

> 按符号锚定（不写行号，防漂移）。改到相关代码时同步更新本文件。

## Series / Panel

- `Series`：面板内的一条序列——各点取值，缺样本为 `None`（断线跳段不造点）。
- `Panel`：一个纵向面板——标题、值域、网格与序列组。这里不产生任何 SVG 字节，落墨在 `super::draw`。

## build_panels

- 按轨收集面板：分类质量、任务轨（逐数据集）、修复成本、judge 均分与端到端延迟——面板出现与否完全由数据决定（无样本整板隐去）。

## push_judge_panel 的零分不画点

- count == 0（judge 启用但全失败）不画点：average 恒为 0.0，画出来会在 1..=5 轴上被误读成「评了 0 分」——与延迟面板「无样本不画」同口径。

## push_panel

- 收一个面板：全部序列都缺样本的面板整体跳过，部分缺样本的序列只从图例与曲线里隐去自己。

## dataset_order

- 历史中出现过的数据集，按首次出现序排列（确定性遍历序）。去重期借用各点的数据集名，末尾一次性落成有副本的 `Vec`——每份只复制一次。

## dataset_label

- 数据集显示名（未知 id 原样展示）。

## dataset_rate / dataset_rounds

- `dataset_rate`：单数据集在历史各点的比率；该点缺席数据集或分母为 0 视作缺样本。
- `dataset_rounds`：单数据集在历史各点的修复轮次；该点缺席数据集视作缺样本。
