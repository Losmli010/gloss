# uia（系统（Windows）文本模式读取器）测试记录

> 按符号锚定（不写行号，防漂移）。改到相关测试时同步更新本文件。
> 测试代码禁止注释（AGENTS.md“注释纪律”节），测试的验收意图与辅助契约记录在此。

## 测试目标与层

- 第一层（L1）：错误映射（`interpret`）的纯逻辑矩阵，系统调用面以结果值
  替身驱动，不碰真实组件对象模型（COM）。

## 辅助契约

- 非空文本逐字采纳（含两端空白的原文——修剪在组合通道入口）。
- 空串＝属性在而无选区，报空选区（组合通道先让渡补读）；空值＝超上限
  拒取，报读取不可用（值得一次兜底）。
- 文本模式缺席的自造标记码与任意失败码都报读取不可用（组合通道落兜底）；
  权限拒绝语义在本平台不存在。

## 惰性创建（2026-11-06 评审整改）

- `uia_first_use_creates_the_object_once_and_reuses_it`：惰性槽首次取用
  恰创建一次，后续取用复用同一对象（替身值钉住“创建一次”与“同一性”）。
- `uia_a_failed_creation_is_never_retried`：创建失败即终态，后续读取不再
  重试（失败路径不逐读添系统调用）。
- `uia_reader_starts_pending_without_touching_com`：构造零系统调用——读取
  器在主线程（组装段）构造，创建必须留给事件线程上的首次读取；这是评审
  整改的行为契约（构造触碰组件对象模型（COM）即测试红）。
