# uia（系统（Windows）文本模式读取器）测试记录

> 按符号锚定（不写行号，防漂移）。改到相关测试时同步更新本文件。
> 测试代码禁止注释（AGENTS.md“注释纪律”节），测试的验收意图与辅助契约记录在此。

## 测试目标与层

- 第一层（L1）：错误映射（`interpret`）的纯逻辑矩阵，系统调用面以结果值
  替身驱动，不碰真实组件对象模型（COM）。

## 辅助契约

- 非空文本逐字采纳（含两端空白的原文——修剪在组合通道入口）。
- 空串＝属性在而无选区，报空选区（组合通道先让渡补读）；空值＝超上限
  拒取，报读取不可用（值得一次兜底）。
- 文本模式缺席的自造标记码与任意失败码都报读取不可用（组合通道落兜底）；
  权限拒绝语义在本平台不存在。
