## 骨架上提（2026-11-21，代码克隆治理 G3-P2）

- 三条语义测试（缺条目读空、删除缺条目幂等、缓存读写一致）自两侧平台目录合并到本模块：此前钥匙串半边与凭据半边各持逐字同体的一份（克隆门禁基线登记的待消对），骨架上提后语义由骨架层锁定，两侧调用面各自的缺条目读空路径由其并发首读测试继续覆盖（见两侧测试记录）。
- 断言语义与合并前逐字一致；测试载体从真系统存储改为替身底层读写删（`FakeIo`）：骨架语义不触真实系统调用（映射缺失路径由两侧调用面测试守住），替身内存图使本模块保持第一层（纯逻辑）与零平台依赖。缓存直填入口经共享缓存引用（`cache.cached_map`），与合并前经私有入口直填同义。

## 回填落定入底层读（2026-11-21，评审定案落点）

- 评审抓出回填随骨架上移移出钥匙串首读闸门临界区、并发首读可二次触底层读（竞态测试实证可红）；修复后未命中读的回填由底层读在其同步内经落定助手完成（取舍见 secret 决策记录），替身底层件（`FakeIo`）随契约改为读后落定，三条语义测试断言不变。
- `settle_keeps_the_first_answer_for_a_key`：落定助手的让渡语义自钥匙串与凭据两侧的编排中单源到共享层后，在此钉住——同键第二次落定不覆盖先落答案（并发写删胜出）；两侧真实路径的该语义此前只靠记录口径守护，无可执行断言。

## 辅助

- FakeIo：内存图替身底层读写删：读写删按图存取、缺条目回空；持 `Arc` 使替身可克隆（骨架 `Clone` 语义要求底层件可克隆，克隆共享同一张替身图）。
- FailingIo：恒失败替身底层读写删：锁定错误降级——失败原样上抛为配置错误形态、失败读不落缓存（骨架不缓存失败答案，后续读取不拿错误顶数）。
- test_store：测试专用服务名（与出厂条目隔离）加替身底层件的骨架存储。
