## 约束“egui 上下文统一装入点”（实现）

- 2026-09-23 两个 egui 上下文（浮层、设置窗）都必须经 `ui/context.rs` 装上字体与主题；业务侧直接 `Context::default()` 或直接调 `set_fonts` / `set_theme` 都会被扫到。逃逸口是行内注 `constraints:allow-context` 并写明缘由（沿用 `secrets:allow` 惯例）。
- 匹配前去掉空白，带空格的写法同样命中；已知盲区（grep 判定的代价）：类型别名（`use egui::Context as C; C::default()`）与 `let c: Context = Default::default()` 这类写法扫不到。

## 约束“FFI 声明集中”（实现）

- 2026-09-23 平台 FFI 的 extern 声明只允许出现在 `gloss-platform` 的 `src/ffi/`（R2 收编的正是这类重复：`AXIsProcessTrusted` 两处两种写法、粘贴板 extern 两处、CF 守卫三份）。
- 匹配前先归一空白（`extern "C"  {`、`extern"C"{` 都命中），与“egui 上下文统一装入点”同做法。
- 只管 extern **块**（Rust 里 C 声明只能写在块里），`extern "C" fn name(...)` 形式的回调定义不算声明——那些函数贴着各自的业务模块（如 `events/mod.rs::fire`、`events/mouse.rs::raw_callback`），已用自测用例钉住不误报。
- 逃逸口：目前没有；确需就地声明时应先改本模块与 AGENTS.md，而不是在业务模块里破例。

## 反馈迁移（2026-10-25，PR2c）

- 两条判罚各挂规则标识（上下文装入点、跨语言声明集中），判罚消息去掉“constraint violation (xxx)”前缀；证据行从截断四十字符改完整违规行并带行号（取证改为带行号枚举取首条），判定口径不变（仍每文件一条）。
- 首个违规行的抽取收敛为共享的取首条助手：两条检查共用“逐行枚举、放行标记行跳过、空白归一后匹配”的口径，匹配正则照旧两套（上下文装入点、跨语言声明集中）。
- 外部函数接口集中的匹配式改为转义后的字面串常量：源代码的外部函数接口块开头形态归一空白后匹配的语义逐字保留，模式不再内联在循环体里。

## 豁免缘由机器化（2026-10-26，PR7）

- 标记行同时命中上下文装入点模式才构成豁免现场：此时缺同行非空缘由即按通用域的缺缘由标识报告，豁免本身不变（该行仍从装入点判罚里跳过）；不命中模式的标记行是惰性提及，不判罚。
- 新增的缺缘由扫描与取首条助手共用同一读取（并轨入口下走共享缓存）与同一空白归一口径，不改变装入点判罚的“每文件取首条”语义。
