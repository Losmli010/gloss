## 目录现状（2026-11-06，Windows 移植 P2①，更新同日 P0 口径）

- 核心链路（划词）落地：低级鼠标钩子手势源、用户界面自动化（UIA）主路
  加按键注入兜底的取材通道、前台窗口进程查询加敏感名单的场景探针；外部
  函数接口（FFI）目录按系统（macOS）同构规则收口系统库绑定与组件对象
  模型（COM）面。平台事件线程跑消息泵（Win32）宿主并在启动序初始化单
  线程套间（STA）。
- 尚未落地的能力（外观图标、托盘菜单、剪贴板监视与图片取材、密钥存储、
  区域名读取）保留同名镜像桩，未实现的端口一律返回平台未支持
  （PlatformUnsupported）；渲染（P2②）按移植方案另行落地，届时
  AGENTS.md 架构速览随动（P2④）。
- 2026-11-06（P1 合入后适配）端口桩口径沿用：消费方不引用本目录类型，
  手势源与取材通道都实现核心层端口（装配句柄 `Platform::connect` 是唯一
  构造点，落地前后一致）；未落地能力的桩未动。

## 配置与密钥存储、桌面入口落地（2026-11-10，Windows 移植 P3b 后续）

- 配置与密钥存储由同名镜像桩落为真实实现（storage：文件加凭据管理器），桌面入口落为桌面快捷方式重建（shortcut）——此前“尚未落地的能力保留同名镜像桩”的口径就此收窄：未实现端口一律返回平台未支持（PlatformUnsupported）的规则不变，桩清单里不再有存储。
