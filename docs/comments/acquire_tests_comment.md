## 辅助

- ScriptedTextAcquirer：文本取材替身——注入读取结果（成功或失败），还原收尾经共享序表记“restore”一笔；锁定“事件先于还原”的测试据此读序。
- QueuedImageReader：剪贴板图片读取替身——注入逐次读取结果队列，队空按无数据（`Ok(None)`）兜底。
- QueuedGestureSource / ObservedClipboardWatcher：手势源与剪贴板监视替身——前者注入并清空坐标队列，后者每拍产一条观察。
- send_log / send_marker：发送闭包替身——前者把事件收进共享事件表，后者在序表记“event”一笔并同存事件；序表断言（`["event", "restore"]`）是时序不变量的判罚点。
- granted_then_silent：权限观察替身——首次作答真、其后恒假（平台闭包“落定只产出一次”的内部语义在替身侧建模）。

## 断言口径

- 时序：先发通道四事件、后执行还原收尾，成功与失败两路都锁（资损敏感：还原不挡弹窗链路）。
- 分流：日志经进程内捕获判级别字段——拒权走 warn（值得引导授权），其余失败不升 warn（日常路径 debug，默认过滤器下不可见即判罚点）；错误本体只经 `TaskFailed` 事件比对变体，不做文案断言。
- 映射：三类事件源逐源驱动，产物按序、按形比对；降级闩锁以“多次轮询恰一条告警”锁定一次性。
- 敏感纪律：选区与图像字节用无意义夹具词，断言不复制生产日志文案之外的用户可感内容。
