## ClipboardFallbackReader（2026-11-06，Windows 移植 P2①）

- 与系统（macOS）兜底读取器同构的确认语义：快照 → 注入复制快捷键 → 序列
  号轮询确认 → 读回 → 读回成功且现值未变才恢复。差异只在确认探针：系统
  （macOS）用粘贴板同步标志的闩锁，系统（Windows）用剪贴板序列号差
  （`ChangeMonitor` 记基线，代数即现值）——序列号是系统级单调计数，无闩锁
  语义需要。
- 确认失败重注入一轮再等一个完整超时窗口（与系统（macOS）同参数）：注入
  被静默丢弃（提权进程）或目标未响应时序列号不动，兜底轮按普通获取失败
  上抛（`SelectionUnavailable`），不区分提权与不支持（移植方案定案：不做
  提权）。
- `FallbackSettle` 与系统（macOS）同名同形：恢复决策（成功且现值未变才
  恢复；失败轮一律不恢复）与写盘归因（轮次闩锁自报计数）装在收尾结构里，
  调用方在取材产物上抛之后收口。轮次闩锁在系统（Windows）尚是占位（图片
  哨兵随 P2③ 落地），计数归因暂为无害空转。
- 未确认时 unwind 路径同样恢复（`PendingRestore` 的 Drop）——调用方崩溃
  不把注入产物留在板上（与系统（macOS）同契约）。

## wait_for_write

- 纯时序函数：给定基线、探针与截止时间，轮询到代数前进或超时；轮询间隔
  与确认超时常量与本文件头（系统（macOS）同值：八百毫秒确认窗、三十毫秒
  轮询）。
