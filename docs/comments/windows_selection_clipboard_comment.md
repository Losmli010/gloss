## ClipboardFallbackReader（2026-11-06，Windows 移植 P2①；绑定面随方案 A2 收窄）

- 确认探针的平台差异：系统（macOS）用粘贴板同步标志的闩锁，系统
  （Windows）用剪贴板序列号差（`ChangeMonitor` 记基线，代数即现值）——序
  列号是系统级单调计数，无闩锁语义需要。
- 注入被静默丢弃（对提权进程的注入，用户界面特权隔离（UIPI））或目标未
  响应时序列号不动，兜底轮按普通获取失败上抛（`SelectionUnavailable`），
  不区分提权与不支持（移植方案定案：不做提权）。
- 装配骨架上提（2026-11-21，克隆门禁 G3-P1）：板创建守卫与板文本读取接线
  随共享装配骨架（`read_with_fallback`）归共享层，本侧只留绑定束
  （`FallbackBindings`）的五原语——基线计数取序列号、快照判定、还原、序
  列号监视与 SendInput 注入；流程语义见 fallback 记录。
- 文本快照恢复的写盘计量（2026-11-21）：文本写回经跨平台兜底库触板（清板加放回，至少两跳），写盘数改为开板前后各取一次剪贴板序列号求差实测、读数缺席按单跳计——固定单跳少报与注入侧同族（共享流程同步改实测，见 fallback 记录），图像风格恢复的计量不变（写回面原生按真实跳变自报）。失败轮同样按实测部分跳变上报（清板已发生而放回失败时不再丢弃），成功轮读数缺席按下界两跳计、失败轮读数缺席记零，序列号回绕（约 2^32 次）会静默计零——极窄边界接受。计量窗口自取序号起到写回定稿止，含跨平台兜底库建板的重试期（窗口内外来写入并入实测差，多报吞掉其后少量用户复制，受兜底库私有接口限制无法收窄）。
