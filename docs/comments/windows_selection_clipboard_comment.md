## ClipboardFallbackReader（2026-11-06，Windows 移植 P2①；绑定面随方案 A2 收窄）

- 确认探针的平台差异：系统（macOS）用粘贴板同步标志的闩锁，系统
  （Windows）用剪贴板序列号差（`ChangeMonitor` 记基线，代数即现值）——序
  列号是系统级单调计数，无闩锁语义需要。
- 注入被静默丢弃（对提权进程的注入，用户界面特权隔离（UIPI））或目标未
  响应时序列号不动，兜底轮按普通获取失败上抛（`SelectionUnavailable`），
  不区分提权与不支持（移植方案定案：不做提权）。
