## 验收意图（2026-11-28 首版）

- 两规则在假仓夹具上正反两向逐条锁定：白名单四条过渡存量按真实路径复刻（依赖三边与引导四处的放行即白名单在跑的证明）；红牌七类各自成例——反向边（dev 桶导入门禁基建）、未登记跨桶边、叶桶导入、同目录冗余引导、测试文件插入、多处插入、解析失败。
- 定案形态的放行例两向：跨桶单点导入指 scripts 根（依赖单向化后的终态形态）与子包文件插宿主桶根；放行标记带缘由放行与缺缘由判罚两向同锁。
- 聚合路由用例断言两条通过行进聚合序，领域模块少挂即红；解析失败按失败关闭出基础设施条目，两类通过行同时缺席。
- 真实仓库的白名单生效由约束配方承担（验收命令的全绿即证明），不进单测；标识登记一致性由统一诊断出口的一致性测试承担，本域不重复。
