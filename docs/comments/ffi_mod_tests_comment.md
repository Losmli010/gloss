## 测试行为速览（BDD）

已统一迁往 docs/tests/bdd.md（git 追踪，以测试代码为唯一事实来源）；本文件只留缘由与形态说明。

## 辅助契约

- 测试跑真实 CoreFoundation（无宿主依赖、无授权要求、无共享状态），可在 CI 的 macos runner 上并行跑。
- `string_from_rejects_non_string_objects` 传 `usize::MAX` 作上界：让「类型检查」成为唯一可能的拒绝原因——上界给小了，字节上界那条判定会替类型检查兜底，删掉类型检查测试仍然绿。
- `string_from_respects_the_byte_ceiling` 只能证明「超限返回 None」，证不了「判定发生在分配之前」（两者可观测结果相同，除非引入分配计数器）；场景描述以代码为准。

## 未覆盖项（记录）

- `converted != len` 的失败路径没有测试：现有一切输入都来自 `cf_string`，恒能整串转换。要覆盖需造一个编码不全的 CFString（例如 UTF-16 构造的孤立代理项），成本高于收益，留作需要时再补。
- `cf_string` 的「守卫是否过早释放」在进程内不可证伪（释放后的内存仍可读），Miri/Valgrind 目前只覆盖 gloss-core。签名与内存管理规则的一致性靠 `ffi/` 的单点收编 + 人工评审。
