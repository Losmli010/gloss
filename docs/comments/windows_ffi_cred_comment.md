## 凭据管理器封装（2026-11-10，Windows 移植 P3b 后续）

- 只封装通用凭据（CRED_TYPE_GENERIC）的读、写、删：持久域取本机（CRED_PERSIST_LOCAL_MACHINE），载荷是原始字节，编解码与缓存归密钥半边——FFI 只面对系统接口。
- 条目不存在不是错误：读取回空表值、删除恒成功，错误码（1168）按系统错误到结果句柄的映射预计算判空——语义与核心层端口契约一致，调用方不写错误码分支。
- 读取取记录前先判空：成功出参按接口契约必为有效记录，但解引用前显式防御空指针（构造层面防崩，代码扫描的解引用告警也以此可验证），空记录按错误上抛而非 `panic`。
- 密钥红线：载荷不进日志、不进错误消息，错误只带系统侧错误码与系统消息；单块不变量注释覆盖指针生命周期（读取记录经 CredFree 释放、写入记录只借宽串与载荷）。
