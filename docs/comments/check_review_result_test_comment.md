## 验收意图

- 空正文分支、骨架小节、声明同源与书写规则的单测覆盖：合规提交放行、空正文与纯空白
  正文并入空正文规则单条判罚（不叠加骨架与声明两域，修复指引指向补写评审结果）、
  缺段、缺声明、未知声明、块外声明忽略、正文模板缺失按基础设施失败关闭、英文句被书
  写规则拦下。
- 命令行端到端锁定退出码三态（通过零、违规一、用法错误二）与违规输出进标准错误，
  是持续集成作业与客户端钩子共同的调用契约。
