## 验收意图（tests 入口，2026-10-31 首版）

- 规则级用例直调 `check` 入口，样本为内存字符串；判罚断言落到规则标识、消息形态与列号，豁免断言落到空输出——测试红说明判定行为变了，而不是实现重构了。
- 解析树行为锁定：硬换行的括号对与跨行行内代码在单元内合并后豁免（`test_softwrap_paren_pair_passes`、`test_corner_inside_cross_line_code_span_exempt`）——这是逐行判罚换解析树判定的核心收益，回归即说明单元模型漂移。
- 邻接豁免面锁定：数字两侧（日期、小数、千分位）、文件名扩展与章节号句点放行（`test_digit_adjacent_punct_passes` 等三例）；豁免放宽或收紧都要先改这里再改判定。
- 配对三形态（单闭、多开、交错）各锁一例，列号断言钉住定位精度；直角引号不进配对栈由“出现即罚”覆盖，两规则互斥不重复计罚。
- 门禁级：受检面边界（记录目录内外的分派与文档书写门禁互斥）、干净样本零输出、违规样本带规则标识与修复指引、退出码随判罚翻转；路由用例经 `check_comments.collect` 显式清单确认第四门禁并入生效。
