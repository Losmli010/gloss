## 可执行文件图标嵌入（2026-11-10，Windows 移植 P3b 后续）

- 系统（Windows）目标把应用图标（Gloss.ico）编译进可执行文件资源段：任务栏、桌面快捷方式与文件管理器显示品牌图标；系统（macOS）的图标随应用包资源走（cargo-bundle 配置节），构建脚本对其他目标为无操作。
- 门按构建目标的系统取（CARGO_CFG_TARGET_OS），宿主差异不进判据；发布流水线仅在系统（Windows）运行器上构建该目标，资源编译器（rc.exe）随 MSVC 工具链可用。
- 资源编译的调用面随宿主系统门控（`#[cfg(target_os = "windows")]`）：目标专属构建依赖按构建目标选择，宿主为其他系统时编译面没有该依赖——首次推送的 CI 在 ubuntu 检查与系统（macOS）构建腿上即败于该点，评审后补上宿主门（组合门下仅剩的不可达区是系统（Windows）宿主跨构建其他目标，不在任何流水线上）。
- 构建脚本自身不允许静默失败：资源编译出错时经标准错误报告并以非零退出码终止构建——标准错误放行标记注明缘由（此刻应用进程尚不存在，日志出口未装配）。
