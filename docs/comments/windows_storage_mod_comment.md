## 组合存储桩（2026-11-05，Windows 移植 P0）→ 已由真实实现替换（2026-11-10）

- 原 P0 桩口径：构造可用、逐操作失败，文档半边与密钥半边按移植方案后续阶段补齐——本条留档沿革，最新口径见下节。

## 组合存储落地（2026-11-10，Windows 移植 P3b 后续）

- 与系统（macOS）组合存储同名镜像：文档半边（file，TOML 文件）加密钥半边（cred，凭据管理器），组合体同时实现配置持久化（ConfigStore）与密钥（SecretStore）两个端口，组装点注入的就是组合体；应用壳的既有降级路径（load 失败落出厂默认）保留为最后防线，正常路径不再走到。
- 密钥半边在组合体内只取一份实例：文档与密钥经同一组合体注入（入口的 config_store 与 secret_store 同源），设置页与任务链路共享密钥缓存。
