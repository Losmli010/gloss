# fields.rs 决策记录

> 按符号锚定（不写行号，防漂移）。改到相关代码时同步更新本文件。

## `connection_section`

- 模型区：服务地址 → 密钥（写 keychain，不进配置）→ 模型标识。三个字段标签 2026-10-28 全部出自文案表（Base URL / API Key 两标签原硬编码在字段行，随显示调用点门禁入表；“模型 ID”同日去英文）。
- 重新输入即撤销“清除”意图。
- 2026-11-03 密钥行改右到左排布（按钮先落右缘，输入框吃满剩余宽）：密钥输入框与清除按钮的总宽与服务地址输入框严格等宽、左右缘对齐——旧实现用预留常量（`CLEAR_BUTTON_RESERVE`，按钮宽 + 间距的估算值）截输入框宽，按钮自然宽与估算值不等导致两行右缘错位；排布法由界面库自身布局求解，无估算量，常量随撤（样式层档位随本提交一并删除）。

## `general_section`

- 通用区：目标语言、界面语言、界面主题、缓存有效期（上限由控件钳制）、
  剪贴板图片监听开关（保存时整体上交，热切换不要求重启）。

## `update_section`

- 更新区：相位标签 + 单一动作按钮（两道确认、取消与失败重试都收敛在
  这一行）。`Checking` 与 `ReadyToRestart` 无可点动作；替换步失败附
  安装指引（只读卷 / 权限不足的出口，见分发设计 §4.4）。

## `update_label`

- 相位标签：借自常驻文案表，只有带占位符的相位才拼新串。

## `failed_label`

- 失败相位的标签：按失败步骤区分措辞（卡在哪一步，就重试哪一步）。

## `update_button`

- 相位动作：`None` 表示该相位无可点动作（忙碌中与就绪待重启）。

## `LANG_CHOICES`

- UI 固定可选的 2 语种（2026-10-30 语言收敛 D5：日语、韩语、法语与自定义目标语言退役，存量配置退役值由配置装载处有痕降级；条目形从每次调用的函数指针改为常量数组——变体收敛后清单不再需要按调用构造）。

## `lang_label`

- 语言标签：产物语言（译文给谁看），与界面语言分属两张表。

## `lang_combo`

- 目标语言下拉。

## `language_label`

- 界面语言标签（三态偏好，落定见 `Language::resolve`）。

## `language_combo`

- 界面语言下拉：本项同时决定 prompt 模板语言（`Language::resolve`）与本表
  的选表依据；保存后下一次触发与下一帧界面即生效。

## `theme_combo`

- 主题标签与下拉（消费在壳侧，见 `app::theme`）。

## 按钮与下拉的悬停手型

- 2026-10-28 清除密钥、更新区动作按钮与目标语言、界面语言、主题三个下拉触发钮挂手型光标；下拉取 `show_ui` 返回的触发钮响应统一挂（当时菜单项保留界面库缺省箭头，见下条）。
- 2026-11-03 下拉选项悬停观感对齐按钮（用户反馈）：悬停底与描边实测本就与按钮同源——界面库 0.36 的弹层选项是 `frame(true)` 的按钮形制，悬停填充同为 `widgets.hovered`（快照实测两侧填充同为 `220,220,220`，描边圆角一致），无需改样式；真正不一致的是光标——选项悬停落界面库缺省箭头，按钮是手型。`choice_option` 助手给选项统一挂手型，三个下拉共用；选中项的朱砂底为既定品牌语义（见 context 记录），悬停不改其色。
