## 分组（2026-11-06，Windows 移植 P2①）

- 与系统（macOS）外部函数接口同构的唯一落点：系统库绑定（windows 系依赖）
  的全部 `unsafe` 调用与类型出面集中本目录，业务模块不直接触达系统库绑定
  ——调用面与安全性依据只有一处需要审计。按关注面分文件：组件对象模型
  （com）、低级鼠标钩子与消息泵（hook）、按键注入（inject）、剪贴板序列号
  与格式清单（board）、前台窗口进程查询（foreground）、用户界面自动化
  （uia）。
- 与系统（macOS）的差异：系统（macOS）侧大部分框架符号来自语言绑定库的
  声明转发，系统（Windows）侧用微软官方绑定库（windows）——本目录转发其
  类型与常量（消息结构、句柄类型），`unsafe` 块带单块不变量注释，语义
  与系统（macOS）目录同规。
