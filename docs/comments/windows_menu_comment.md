## 托盘装配桩（2026-11-05，Windows 移植 P0 D6）

- 恒返回未装配（false）：托盘图标 + 托盘菜单（tray-icon）是 D6 的行为差异项，随 P2 ④ 落地；壳侧既有降级（无菜单栏运行、设置入口仍可经浮层动作打开）在桩期成立。

- 2026-11-05（P1）自由函数镜像改为菜单装配端口的桩实现（`SystemMenuController`，与系统（macOS）实现同名镜像）：仍报告未装配，回调收装箱对象。

## 托盘落地（2026-11-07，Windows 移植 P2④ · D6）

- 托盘图标常驻通知区域，右键弹托盘菜单（设置、分隔线、退出），左键行为按方案后置——`with_menu_on_left_click(false)` 只关菜单随左键弹出，不订阅托盘点击事件（托盘库的点击事件通道保持未接）。装配点在主线程：托盘库要求装配线程跑消息泵，主线程的窗口库（winit）事件循环即宿主；托盘窗口消息随主线程消息循环分发。
- 退出动作经端口新增的 `on_quit` 回调上交壳侧（见 ports 记录），设置动作沿用既有回调；两回调收进互斥锁包裹的同步收口（`MenuActions`）：托盘库的词条动作回调契约要求 `Send + Sync`，壳侧回调只保 `Send`。回调只在主线程触发，锁无争用；锁中毒说明持锁回调已 panic，后续点击按降级丢弃——降级留痕（2026-11-07，移植评审遗留 D1）：中毒分支经日志宏出口带词条标识留 `warn`，不是静默吞错（近不可达路径也要守“降级必有痕”的口径）。
- 托盘句柄存主线程的线程局部槽（与系统（macOS）菜单的动作对象同款驻留方式）：句柄释放即撤图标，驻留即“随主线程活多久”。
- 图标复用坞图标资产（品牌同源，`include_bytes!` 装配），经图像库解码为原始位图（RGBA）交给托盘库——托盘库不吃编码格式，只收位图；解码失败与托盘装配失败一律告警降级返回未装配，壳侧既有降级（无菜单栏运行、设置入口仍可经浮层动作打开）在真实现下同样成立。
- 词条动作经托盘库的菜单事件处理器（`MenuEvent::set_event_handler`）分派：该处理器是进程级单件（一次装配即定），词条标识常量化（`gloss-settings`/`gloss-quit`），事件按标识分派到回调。

## 词条表上移共享层（2026-11-14，方案 A7 随 P2）

- 与系统（macOS）同构的双语词条表与档位查取上移平台中立共享层（common），
  本模块按托盘装配所需词条（设置、退出）取用，词条值与菜单行为零变化；
  缘由随词条表迁入共享词条记录。
