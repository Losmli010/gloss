## 权限预检桩（2026-11-05，Windows 移植 P0）

- 预检恒放行、引导为无操作：Windows 无系统级授权门，UIA 不索取权限（移植方案能力映射的定案）；与 macOS 的“缺授权即拒读”不同，该目标的阻塞点在取材桩（`PlatformUnsupported`），不在权限。
- `AccessibilityWatch` 保留同名占位、轮询恒不放行：真实现落地时决定保留或移除。
- 2026-11-05（P1）新增 `SystemPermissionProbe` 实现核心层权限探针端口（与系统（macOS）实现同名镜像）：预检恒放行、引导为无操作、授权监视轮询恒不放行，与占位语义一致。

## 监视占位收敛（2026-11-07，Windows 移植 P2④）

- `AccessibilityWatch` 占位移除，`watch` 恒返回不放行闭包：P0 桩期留的“真实现落地时决定保留或移除”在此定案——Windows 无系统级授权门，授权事件永不来，节流监视是死代码；预检恒放行、引导为无操作的语义不变。
