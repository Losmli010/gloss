## 桌面入口装配（2026-11-10，Windows 移植 P3b 后续）

- 便携压缩包即安装形态，可执行文件落到哪里，桌面入口就应在哪里：每次启动幂等重建一份快捷方式——应用原位更新后路径不变、链接保持有效；可执行文件挪位或换位后重建让入口跟随实际位置。省去旧链接读回比对：写一次外壳链接的成本毫秒级，换来免维护的自愈语义。
- 可执行文件本身已在桌面上时不建自指链接；链接名取打包名（Gloss），与发布产物名一致。
- 失败是降级信号不阻断启动：调用方（组装段）按痕告警，与图标装配的降级语义同规。
- 真实落盘路径（桌面 `.lnk` 可见）走人工测试清单，不进自动化。
