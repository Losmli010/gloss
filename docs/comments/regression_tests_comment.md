# regression.rs（gloss-eval）内联测试辅助契约

> 按符号锚定（不写行号，防漂移）。改到相关代码时同步更新本文件。
> 本文件随仓库跟踪（docs/comments/ 入库），改名与合并用 `git mv` 保留历史；文件内不留指向本文件的指针。

- 2026-11-01 五态矩阵按标注分支分组钉判定：标注合格分支——相等过、
  不等回归（带差异摘要与 `structured_match=false`）、契约降级先于比较
  短路（回归且无结构化比较）；标注不合格分支——不等改、等未改善；
  基线或标注缺该条待比；引擎故障回归字段恒置空——判序先到先得（计划
  §6.5）。
- 2026-11-01 `normalization_ignores_whitespace_and_example_order` 钉规
  范化语义：音标空白与例证乱序不产生回归误报（`trim` 加多重集排序）；
  排序按字节序定序，不钉拼音或笔画词表——措辞与顺序噪声是本轴的豁免
  面，语义差异照罚（计划 §6.5）。
- 2026-11-01 分类回归测试钉按子类分派比较：`Fallback` 两侧一致判过
  （生产校验器把它落到通用任务），类别不同判改并带类别差异摘要——
  分类基线比较走类别相等，不走结构化字段。
- 2026-11-01 `golden_baseline_rounds_concatenate_chunk_fragments` 钉基
  线行形状：末轮分片无分隔直连、多轮轨迹只取末轮（结算轮）——分片拼
  接错了会把流式增量当多轮，回归判定整体失真（计划 §6.2）。
- 2026-11-01 不可比测试钉三态边界：本轮降级（标注不合格分支）判改且
  `structured_match` 为空、摘要说明降级；基线原文损坏判回归、摘要说明
  基线不可解析——不可比不算相等也不按字段差计摘要，摘要文案进明细
  供检视页直读。
