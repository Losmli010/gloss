## 缩放热区（resize_handle）

- 2026-10-28 卡片下缘、右缘与右下角三段缩放热区（`overlay_resize_south/east/corner`，拖拽语义，光标随向），右下角画三道斜纹握把示意。热区是 `draw` 帧末注册的 `interact` 层：注册晚于全部内容控件，命中判定压在内容之上，但热区只占卡片外缘 `resize::HOTSPOT`（4 像素）与角部 `resize::CORNER`（14 像素）——页脚按钮与水印都收在卡片内边距之内，实际零重叠，点击不受影响。
- 期望尺寸算法与页头拖动同构：按压帧记物理按压点与当时窗口尺寸（`viewport_rect`），拖动帧按 `(指针物理位移 / 像素密度)` 累计到基点上——绝对目标而非逐帧增量，丢帧不漂移。三段热区共享一组按压状态（同一时刻至多一个拖拽在途），无拖拽帧清按压态。
- 粘性：`user_size` 一旦置位就逐帧随输出上交（松手不清），壳侧据此接管宽高（见 windows 记录）；会话重置（显隐）时随 `reset_drag_state` 清空。指针丢失（`interact_pos` 为 `None`）的帧跳过更新但不打断粘性——若用 `?` 提前返回，壳侧会在该帧回退到内容自适应，窗口形状被顶回去。
- 无障碍：三段热区共用“调整浮层大小”词条（中英双表各一条，词条数钉子 88→89）。
- 基线重录附记：三份流式基线（含呼吸点）随本次改动连带页脚呼吸点亚像素抗锯齿漂移（调色板结构体增字段的连锁渲染微移，36 像素块、低于判容差、肉眼不可辨），重录实验确认确定性复现，沿革已录行为清单。

## 缩放热区八角化与意图协议（2026-10-29）

- 热区从三段扩到八段（`overlay_resize_north/south/east/west/north_west/north_east/south_west/south_east`）：四条边带收在两角之间互不重叠，四角整块归角部热区；右下角斜纹握把示意撤销（用户定稿：不画握把），`geometry::resize` 的 `GRIP_*` 四常量随之移除，基线全量重录（像素差异仅右下角握把区）。
- 界面侧不再自己算期望尺寸：窗口相对坐标系里算西、北向拖动会吃进窗口自身位移的反馈（窗口每帧平移，指针的窗口内坐标随之后退，期望尺寸收敛到一半速并围绕目标振荡），所以上交的改为**缩放意图** `OverlayResize`——`Press { edges, window, pointer }`（按下帧：边界组合、按下时刻窗口尺寸、窗口内指针位置）、`Drag { edges, pointer }`（拖动帧）、`Settle`（松开后的粘性帧）。全局坐标、锚定与钳制全在壳侧（见 windows 记录），界面侧只认窗口内坐标。
- `Press` 只在 `drag_started` 且指针在场时上交并置位会话标记 `resizing`：指针丢失的按下帧不置位——否则会话开在壳侧没有锚点的状态，后续 `Drag` 全部空转。松手后逐帧粘性上交 `Settle`（壳侧不再走内容自适应尺寸），会话重置（显隐）时随 `reset_drag_state` 清空。
- 边界组合是数据（`ResizeEdges` 四布尔）不是枚举：八段热区两两组合直接落位，壳侧锚定求解按位展开，新增组合（如中键副屏场景）不再加变体。
- 无障碍：八段热区共用“调整浮层大小”词条，词条不变。

## `OverlaySizing`

- 本帧期望的浮层高（逻辑点，含内边距与框线）——宽度恒为 `OVERLAY_WIDTH`、不随
  内容变化（窗口创建与每帧期望宽同源此常量，不经此结构传递），只有高度随内容。
  `height`：期望窗口高度（完整内容高，壳侧按显示器钳制）。尺寸半边与缩放意图
  同在本文件：都是每帧绘制产物里壳侧落窗用的几何契约。
