## 测试目标与层

- 第一层（L1）：写回跳变的计量判定是纯函数，以读数组合与调用数直接驱动，
  不触真实剪贴板；开板、放回与关板的系统调用面仍由真机人工测试与取材
  链路的集成行为覆盖。

## measured_jumps 单测（2026-11-21）

- measured_jumps_prefers_the_paired_reading_and_falls_back_to_the_call_count：
  成对读数才是真实跳变——位图格式族在关板时被系统合成伴随格式，实测差可
  大于放回调用数（钉住写回不得按调用数记账，少报会让恢复回板的图被哨兵判
  成用户复制）；读数缺席回落调用数记账（清板加每次成功放回），回退读数饱
  和为零不产生负数。
