# source_hygiene.py（约束门禁·源码卫生）决策记录

> 按符号锚定（不写行号，防漂移）。改到相关检查时同步更新本文件。
> 本文件随仓库跟踪（docs/comments/ 入库），文件内不留指向本文件的指针。

## 约束「桩副本一致」（实现）

- 桩按包自持（各包的测试桩目录），一份漂移会让两个包的测试在语义不同的假实现上各自通过。
- 引擎桩全文比对；端口桩按节比对——节以「列 0 的 ///」切分（桩的条目文档都在列 0，结构体字段文档有缩进，不会误切）；文件缺失按空节处理（对齐 cmp 空对空）。核心桩目录不存在时整段跳过并输出跳过形态的通过行。

## 约束「文件行数上限」（实现）

- 单个生产源文件不超过五百行（常量即上限），超限即失败；扫描面是根源码目录与各包的源码目录，测试目标与基准不在其列。
- 生产行数按首个列零的测试开关属性行（`#[cfg(test)]`）截断（测试模块按仓库惯例置于文件尾），故文件尾的内联测试模块不计入；带缩进的测试开关行不触发截断（已用自测用例钉住）。
- 存量确需缓冲的，文件前五行写放行标记并注明缘由（同密钥扫描惯例）——豁免是债，新代码一律按职责拆分，不加豁免。
- 违规计数为零才输出通过行（计数含放行豁免数）。

## 约束「残留任务标记」（实现）

- 大写任务标记词四类（见判罚脚本常量，任务记录、待修复、临时与占位）全字匹配，扫全部仓库跟踪文件。
- 正则按英文词界（ASCII）的字节语义对齐命令行全字匹配：汉字不算词字符，任务标记紧贴中文的形态同样命中；小写与词内形态（如 TODOS、下划线连字）不命中。
- 非版本库环境（门禁自测夹具）无跟踪面可扫，2026-10-25 反馈迁移起从静默跳过改为响亮跳过：标准错误打跳过行与原因、退出码零、无通过行；探测与枚举改走统一版本库调用包装，版本库可执行文件缺失属门禁自身故障、失败关闭退出码三。
- 含空字节的文件跳过；单文件读取失败跳过。

## 反馈迁移（2026-10-25，PR2c）

- 三条判罚各挂规则标识（桩漂移、行数上限、任务标记），判罚消息去掉「constraint violation (xxx)」与「leftover task marker:」前缀；证据行完整不截断：任务标记判罚带完整违规行与行号（取证改为带行号枚举取首条）。
- 桩漂移判罚无位置（跨文件比对，行号取零、路径留空）；行数上限判罚位置落在文件（行号取零：超限行数是文件级事实，截断点是实现细节）。
- 源码扫描面为空的失败关闭守卫住本模块（源码空归源码卫生侧的裁决口径）：源码树枚举计数为零即打通用域的空扫描面条目并按退出码三结束；计数在行数上限段枚举时顺带统计，不新增遍历。

## SELF_FILES（豁免面）

- 项目文档（AGENTS.md）是规则本体；本模块与其单测的夹具含任务标记字面量（模式串与用例数据），豁免自命中。拆包前豁免的是旧单文件脚本与其单测，路径随拆包迁移到包内新文件，语义不变。

## 豁免缘由机器化（2026-10-26，PR7）

- 超限文件的头部放行标记（lines:allow）逐个核对同行缘由，缺缘由的标记行按通用域的缺缘由标识报告（每行一条），文件豁免本身不变（仍不计超限、豁免计数照加）；判定收口在 gate_report 的共享助手。
- 未超限文件里的标记是惰性提及，不判罚——豁免现场只存在于真超限的文件里。
