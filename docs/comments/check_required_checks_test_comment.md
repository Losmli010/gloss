## 覆盖范围

- 2026-10-31 三条计划指定样例：全绿（应然集合与打桩必需清单一致，零违规）、缺一个 context 的红灯（缺 Text gates 恰报一条）、评审专属作业不误报（评审作业在场且已设必需时不报）。第四条反漏报用例（评审专属作业缺失时必报）把计划验收「恰好报 Review result check 缺失」锁进测试，防止后续把评审事件整体排除出对账面。
- 2026-10-31 事件过滤两侧：schedule 与 workflow_dispatch 独享的工作流不进应然集合（定时作业不误报）；push 条件作业（对账作业自身）在 PR 链路事件下不收集（自指不发生）。
- 2026-10-31 豁免路径：矩阵展开名不在必需清单也不报，豁免报告行打印在场；解析失败按 INFRA 失败关闭（收集面清空）。
- 2026-10-31 评审补强对应用例：on: 流式映射形态（{pull_request: null}，评审实测的静默漏报形态）与流式清单内嵌映射同判 INFRA 失败关闭；内联标量（on: push，不进应然集合）与流式清单（on: [push, pull_request]，进应然集合）两合法形态不回归——同夹具双文件，push 独享文件零贡献、清单文件贡献 B，同时锁「不红出来」与「不误收」。
- 2026-10-31 评审补强：未知语义断言改走公共出口 runs_on（未知操作数与解析失败按会运行收集断言真），不再触碰私有哨兵；三值求值的已解析两侧仍经 evaluate_condition 断言真假。
