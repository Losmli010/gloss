## 模块的由来（2026-10-30，自 prompt.rs 拆出）

- 降级批注方案给 prompt.rs 增加批注行清单函数后，该文件生产行越过 500 行
  上限（行数门禁）。按职责拆分：语言违约的聚合算法、例句序号拼装与批注
  行清单收口整段迁出——聚合是修复轮行清单与降级批注行的单一事实源，两处
  共用一份；批注行渲染依赖措辞注册表，是提示词层职责，故留在核心库、以
  私有模块并入本包，公开路径经 prompt 重导出不变（gloss_core::prompt::
  violation_briefs 及两个载荷类型）。

## violation_briefs（降级批注方案 §3.5）

- 签名（locale、注入的位置词、违约清单、行上限）到返回结构（行清单加截
  断标记）照设计定稿：位置词是界面文案由调用方注入（例句位带 `{{n}}` 占
  位符按聚合组序号填充，连接符随语言），规则名取注册表规则名区、动作与
  截断注复用注册表原文——界面零措辞逻辑、零聚合逻辑。
- 截断注作为末行进行清单：注册表现值是单一事实源，界面逐行渲染即可。
- 注册表缺席或任一查键未中返回空清单——「注册表缺键回落」是设计定稿的
  泛化回落路径之一；缺键警告由措辞查找层留痕，本函数不重复记。
