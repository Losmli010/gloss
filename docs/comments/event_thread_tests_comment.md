## 测试目标与层

- 第一层（L1）：纯共享形状的进程内时序——抽干顺序、汇点容错与主线程唤醒，
  不涉运行循环宿主；真实线程端到端（spawn 起真线程跑各平台运行循环）的
  组装测试留在两平台的事件模块，见各自测试记录。

## 辅助

- TestCommand / TestEvent / Sink：本地桩类型（平台层不依赖应用层，桩足以驱动共享形状）。
- 三条测试随代码自两平台事件模块迁入（2026-11-07，移植评审遗留 A1）：
  它们测的正是共享形状，原先两平台各留一份拷贝（系统（Windows）侧带
  `pump_` 前缀），迁移后单份登记、行为断言不变。
