## 测试目标与层

- 第一层（L1）：两级通道的组合时序以替身闭包驱动（无真实读取器），节奏
  策略零等待替身，不碰真板与真钟。
- 名称前缀（`combined_`）：与系统（macOS）目录的同构测试互相区分（清单
  限定名唯一按文件绑定，两平台同名文件无法以限定符消歧，见
  windows_events_mod_tests 记录）。

## 辅助契约

- 主路成功不触兜底（兜底惰性）；持续空选区按让渡节奏表跑满再落兜底（恰
  好一次）；空转有值即采纳迟到选区（不兜底）；读取不可用直接落兜底，两
  路皆不可用如实上抛；等待预算耗尽缩短让渡段。
- 归一化：两端空白修剪、内部空白逐字保留、纯空白按空选区语义上抛。
- 节奏表有界且全正（预算耗尽返回空）。
