# web/assets/style.css 设计记录

## 2026-09-28 浅色主题（自深色版改）

- **改浅色的缘由**：Gloss 应用自身的浮层是浅色界面，站点用深色会和产品真实观感脱节；改为浅色后 hero 的“编辑器窗口”保留深色当作屏幕内容（真实对比），“翻译浮层”用白卡贴近应用实际样子。
- **色板**：底 `#F5F9FD`（蓝调浅灰，不是纯白），卡面 `#FFFFFF`，描边 `#DFE9F3/#C9D9EA`，文字 `#17293D/#4E6479/#5E7288` 三档。品牌色沿用应用图标：蓝渐变 `#4AA0E8→#2F7FD0`（按钮/图标），橙色系 `#E06A35/#C75B28/#8A6544` 一族分别用于 H1 渐变尾、代码示意、安装指引标题——都从图标划线的 `#EE7443` 压深而来，保证浅底上的对比度。
- **对比度（code-review 复审后修正）**：`--faint` 从 `#7A8FA5`（白底 ≈3.3:1，不达 AA）加深到 `#5E7288`（≈4.97:1），`.guide .why` 从 `#A98064` 加深到 `#8A6544`；该档大量用于 14px 以下小字，必须满足 4.5:1。
- **蓝色语义分档**：`--blue`（#2F7FD0，图形/强调）、`--blue-deep`（#1D6FBF，浅底上可作文字的图标色）、`#0E74AE`（kicker/pill 等小号强调文字）。浅底上直接用亮青 `#5FC4FF` 一类会对比不足，故深色版的 cyan 全部换档。
- **阴影走蓝调**：`rgba(23,58,94,…)` 而非纯黑，浅色页面里黑阴影显脏。
- **hero 背景纹理**：淡蓝网格 + 双径向光斑（蓝主橙辅），网格线 `rgba(47,127,208,0.06)`，加径向 mask 收敛在 hero 顶部。
- **动画与降级**：`prefers-reduced-motion` 下关掉浮动/流式光标/进场动画；`[hidden]{display:none!important}` 全局兜底（`.pill` 的 display 会覆盖 UA 的 hidden 样式，曾致空 pill 渲染成“—”）。
- **断点**：920px（hero/卡栅格收单列或两列）、640px（下载卡/日志卡单列）、560px（浮层收窄、隐藏 chip-b 防重叠）、480px（原则条单列）。

## 2026-10-02 品牌换装纸墨朱砂

- **缘由**：应用图标定稿宣纸底方案（方案 A 更新，见 `assets/icons/`），官网色板整体跟随，消除“图标纸墨、站点蓝橙”的割裂。
- **色板**：底 `#F6F3EC`（宣纸调浅灰），卡面 `#FFFFFF` 不变，描边 `#E7E2D8/#D8D2C4`，文字 `#16181D/#57606B/#828A95` 三档。品牌 token 更名：`--blue/--blue-deep/--cyan` → `--zhu（#B8432F）/--zhu-deep（#A63D2B）/--zhu-bright（#C74A35）`，主按钮渐变 `#C74A35→#A63D2B`（朱砂印底），H1 渐变改墨→朱砂 `#16181D→#B8432F`。
- **对比度保持**：`--faint #666E79`（宣纸底 ≈4.65:1、白卡 ≈5.16:1）与 `#A63D2B`（小字强调，宣纸底 ≈5.70:1）均过 AA；评审曾发现首版 `#828A95` 仅 3.15:1 不达该档红线（旧版 #5E7288 即为 4.97:1 而选），复审加深修正。阴影从蓝调改暖墨调 `rgba(45,40,34,…)`。
- **模拟窗**：编辑器窗口底从蓝调 `#182740` 改为深卡 `#1D2027`（与产品深卡一致），划词高亮朱砂暗档 `rgba(224,106,82,0.32)` + 下划线 `#E06A52`。
- **hero 纹理**：网格线与光斑改墨调/朱砂调（`rgba(22,24,29,0.05)`、`rgba(184,67,47,0.10)`），保持“克制书卷”而非科技蓝。
