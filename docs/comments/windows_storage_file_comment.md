## 文档半边落地（2026-11-10，Windows 移植 P3b 后续）

- 与系统（macOS）文档半边同名镜像、内容同源（平台目录自持，不跨目标耦合）：本机无法编译验证系统（macOS）目标，跨目标抽取共享模块不可验证，故按平台镜像惯例落两份；去重留待专门的跨平台重构（届时两侧同改、以系统（macOS）持续集成验证）。
- 目录定位经基础目录库（directories）按目标解析：系统（Windows）为漫游应用数据目录（Roaming）下的组合存储目录，与日志根（本地应用数据目录 LocalAppData）分层不同源，各自按惯例落位。
- 写路径原子换名（临时文件加改名）、读路径损坏隔离（原文挪作备份后报错），与系统（macOS）同一套行为契约；同名镜像测试逐条随行，行为在系统（Windows）目标上由本地测试锁定。
