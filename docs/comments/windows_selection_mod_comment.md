## 分组（2026-11-06，Windows 移植 P2①，替换同日 P0 桩）

- 与系统（macOS）同构的三件：用户界面自动化（UIA）文本模式读取器（uia，
  主路）、剪贴板兜底读取器（clipboard，含快照与恢复子模块）、组合读取器
  （composite）。端口契约在核心层的端口模块，读取须在平台事件线程上调用
  （用户界面自动化的套间与线程约束由事件线程启动序承载）。
- 系统系统（macOS）目录里的宿主激活器（activation）在本目录无对应物：
  系统（Windows）没有需要唤醒的无障碍树（无“树未激活”问题），组合通道
  不设激活闸门。
