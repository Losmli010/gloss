## 辅助

- sample_config：带齐全量字段差异的样例配置。
- backups_in：收集目录里的隔离备份（`config.toml.<秒级时间戳>.<序号>.bak`），按名排序。
- MemorySecrets：内存桩密钥存储（组合体转发测试用，不碰真机钥匙串／凭据管理器）；A3 前两平台镜像测试各持一份，上移后全仓唯一。
