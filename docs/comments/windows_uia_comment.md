## UiaReader（2026-11-06，Windows 移植 P2①）

- 选区文本主路：自动化对象在读取器构造时创建，随读取器同生共死——组合
  读取器在平台事件线程上构造（组装段的取材命令处理器），对象因此只在
  事件线程创建与使用，满足用户界面自动化（UIA）的套间与线程固定要求。
  自动化对象创建失败（组件对象模型（COM）套间未就绪等）不恐慌：读取器
  留空，读取恒报不可用，链路退化到剪贴板兜底。
- 错误映射（`interpret`）：有非空文本直读采纳；空串＝属性在而无选区→空
  选区错误（组合通道先让渡补读）；空值（超上限拒取）与错误码（文本模式
  缺席、调用失败）→读取不可用（组合通道落兜底）。系统（Windows）无授权
  门，权限拒绝语义不存在——组合通道没有“权限缺失不兜底”分支。

## MAX_SELECTION_BYTES

- 选区文本字节上限（二百五十六kibibyte）：与系统（macOS）读取器同值；
  超限按读取不可用上抛，不为超大选区扩流式通道。
