## 反馈契约三件套（2026-10-26，gate-pr4）

- 报告格式：违规行首匹配 `error[大写标识]` 且带位置段（本门禁违规不带行号，位置只到文件），证据行与修复行在场；六类标识各一条的夹具断言标识全集。
- 汇总数＝明细数：汇总行的 N 等于实际打印的违规行数（夹具为六）。
- 确定性：同一夹具两次运行，标准输出与标准错误逐字节一致。
- 退出码语义：违规夹具一、用法夹具（参数多于一个、仓库根不存在）二、前置故障三、干净夹具零。
