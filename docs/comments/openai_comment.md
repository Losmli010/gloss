## 方言文件归组（2026-11-18，架构重构方案 §2.3 C3 / §3.4 / §7）

- 请求体构造（request_body.rs）、流式事件（SSE）解码（sse.rs）与失败信封映射（failure.rs）
  是与开放接口（OpenAI）wire 形态绑定的三个文件，归组进 openai 模块：将来接入其它
  提供方时局部修改面收在本目录，方言中立传输（transport.rs）不经它们的名字取条目。
- 只做目录归组，不预建提供方抽象（方案 §7 定案）：没有第二个提供方的需求，trait 化
  只会制造无人实现的接缝；方言条目对传输层以 `pub(crate)` 公布，包外不可见。
- 流式解码（sse.rs）随方言归组而非随传输层住顶层：解码器的分块形状（数据行、完成
  哨兵、错误对象）全是开放接口（OpenAI）兼容端点的 wire 语义，不是传输协议语义。
