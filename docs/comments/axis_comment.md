# axis.rs（gloss-eval trend 子模块）决策记录

> 按符号锚定（不写行号，防漂移）。改到相关代码时同步更新本文件。

## Axis

- 面板纵轴的口径：决定值域与网格刻度的取法。每种轴一个变体，各自的布局
  函数保证网格线恒落在值域内（上下界按构造恒不等，画布映射的除法不会除
  零）。
- 变体随序列清单收窄为两个：`Percent` 百分比轴——固定 0..=100，每 25 一
  条网格（25% 步进，指标汇总面四条序列同轴直读）；`Latency` 延迟轴——零
  起，上界取容纳数据的四等分天花板刻度（延迟只涨不跌，负半轴与顶部留白
  都是无信息的）。
- 旧世界的 `Rounds`（修复轮次轴）与 `Judge`（judge 分 1..=5 轴）随重构步
  骤 5 的序列清单重建删除：修复轮次进了指标表（轮次均值），旧 judge 单分
  被四维 0–100 的模型总体均分取代。

## Axis::layout

- 值域与网格（值域上下界把网格线含在图内；上下界按构造恒不等）。

## Gridline

- 网格刻度：值 + 轴标签文本。

## Unit

- 序列数值在悬浮框与末值标注里的单位与格式。`Percent` 百分比；`Score`
  分值（模型总体均分直读）；`Milliseconds` 毫秒（千位以上换秒）。

## nice_ceiling / QUARTER_CEILINGS

- 延迟轴的上界：容纳最大值的最小四等分友好刻度（阶梯清单先行，超出后取
  最大档的整数倍），保证每条网格线都落在可读的整刻度上——四等分后格数
  与标签值同时可读，替代旧 1-2-5 步长的通用取法。

## format_percent / format_ms / format_trimmed

- 轴刻度与末值标注共用的数值文本：整值不带小数，其余固定一位小数；毫秒
  上千换秒。
