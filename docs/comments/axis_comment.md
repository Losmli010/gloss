# axis.rs（gloss-eval svg 子模块）决策记录

## Axis

- 面板纵轴的口径：决定值域与网格刻度的取法。每种轴一个变体，各自的布局函数保证网格线恒落在值域内（上下界按构造恒不等，画布映射的除法不会除零）。
- 变体：`Percent` 百分比轴——固定 0..=100，每 25 一条网格；`Rounds` 修复轮次轴——0 起，顶值 = 容纳数据的 5 的倍数（至少 10）；`Judge` judge 分轴——1..=5 内按数据跨度留白；`Latency` 延迟轴——数据范围上下各留 10%，网格取 1-2-5 步长。

## Axis::layout

- 值域与网格（值域上下界把网格线含在图内；上下界按构造恒不等）。

## Gridline

- 网格刻度：值 + 轴标签文本。

## Unit

- 序列数值在悬浮框里的单位与格式。`Percent` 百分比（两位小数 + 空格 + %）；`Rounds` 修复轮次（整数 + 轮）；`Score` judge 分（两位小数 + 分）；`Milliseconds` 毫秒（两位小数 + ms）。

## nice_step

- 容纳 span 的最小 1-2-5×10^k 步长。

## fmt_value

- 轴刻度数值文本：整值不带小数，其余固定两位小数。
