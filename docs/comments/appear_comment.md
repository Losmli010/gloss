## 出现动画自浮层模块根拆出（重构计划阶段 4，2026-10-30）

- 淡入推进自浮层模块根（`mod.rs`）整组迁入本文件：绘制入口、视图分发、跨帧
  渲染状态与浮层输出契约留在模块根，为图像视图分支留干净挂点。纯移动：模块
  根重导出 `reset_appear_animation` 原路径承载壳侧调用，下游零改动；时长与重
  绘节拍取动效档（`motion::APPEAR`、`FRAME_BEAT`）的口径不变。

## `appear_t0_id`

- 出现动画起点在 egui memory 里的键。

## `appear_progress`

- 淡入进度——给定居内已流逝秒数，返回 0..=1 的不透明度。

## `appear_fade_in`

- 出现淡入——起点在每次显示（壳侧清除后）的首帧重新写入；进度未满时请求短
  重绘推进动画。kittest 的 animation_time=0 与固定步进让快照恒为完成态，不受
  动画影响。进度未满时请求尽快再来一帧推进淡入（生产中被预测帧时长扣减后接
  近立即重绘，由呈现管道钳到 vsync 帧率）。

## `reset_appear_animation`

- 清除出现动画起点——壳在每次显示时调用，让下一帧重新从 0 淡入（隐藏期无帧
  运行，起点留在居内无副作用；不清除则旧起点让重显直接落在完成态）。
