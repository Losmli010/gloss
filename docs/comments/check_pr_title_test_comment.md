## 验收意图

- 字段抽取的路由与放行面逐条锁定：接口工具按入参字段、命令行按子命令与旗标；
  自动填充、开网页、外部文件、无旗标、运行时取值、外壳分隔符后残余全部放行；
  普通评论命令不进判定面。
- 主入口锁定两端行为：违规退出码二阻断且错误进标准错误（评审路由报缺骨架、
  建链路由报缺必需小节），合规与不相关载荷放行——这是客户端共享配置的提交前
  事件契约。

## 辅助契约

- 模板判定读仓库根的真实正文模板（声明同源解析从模板文件提取），工程目录环境
  变量在导入前钉到仓库根；评审骨架来自门禁常量，评审结果模板文件不经钩子路径
  读取。
- 多行正文的载荷用外壳引用构造真实换行：经对象序列化的转义形态会把换行变成
  字面反斜杠序列，与真实命令行的分词结果不符，属夹具构造陷阱而非被测行为。
