## 覆盖范围（对照方案验收单）

- 2026-11-21 三条判罚规则各一：未登记克隆红牌、放行标记缺缘由条目、基线陈旧条目（体检模式经主入口带假引擎驱动）。
- 2026-11-21 判定顺序短路：标记带缘由的实例不经基线即放行（假报告无基线登记、判罚为零）；标记在任一侧（首侧与次侧各一）都成立。
- 2026-11-21 报告路径分隔符归一：引擎按本机原生分隔符产出绝对路径（Windows 反斜杠）时，归一结果与基线登记的 posix 斜杠同形，配对键可对账。
- 2026-11-21 扩展前缀剥离：报告路径带 Windows 扩展长度前缀（\?\）时先剥再对账，跨平台同例锁定（前缀拼接对 POSIX 是无操作形态，对 Windows 是回归形态）。
- 2026-11-21 放行缘由校验：裸标记同时产出缺缘由条目与红牌（落回后续判定，锁定与密钥门禁不同的取舍）。
- 2026-11-21 基线冻结合计：合计恰等于上限整对放行、超限整对红牌（含原在预算内的克隆）、引擎报告两侧方向互换后合计照算。
- 2026-11-21 任务包拼装：四件套逐项断言（三问内核、覆盖层、上下文与预填建议、验证清单、输出契约），四十一行截断，标识与路径筛选，任务包运行级用例断言真实提示词工件被嵌入。

## 形态决策

- 2026-11-21 单测不拉起真实引擎：判罚口径全部是纯判定函数，用注入的假报告替身驱动；真实引擎的集成面由本仓配方实跑覆盖（判罚模式在空基线下的红牌是预期行为，登记在后续拉取请求完成基线登记后归零）。
- 2026-11-21 引擎调用装配用例 monkeypatch 子进程调用：断言绝对路径旗标、线宽参数、报告器与显式文件清单参数序，报告写进调用方给的输出目录后由被测脚本读回；引擎缺席与非零退出各自锁定失败关闭（退出码三）。
- 2026-11-21 扫描面用临时目录一次性版本库（跟踪清单来自真实版本库调用），与密钥门禁单测同形态；判罚用例直接喂纯数据结构，不起库。
- 2026-11-21 主入口用例经 monkeypatch 替换命令行参数向量与基线路径常量，断言退出码（零、一、二、三）与统一诊断出口的字符串形态（条目头、证据行、修复行、判定辅助指针）。

## 并轨装入器（2026-11-21，克隆治理 G2）

- 装入器路径两例：注入全清单时引擎收到的显式文件清单逐项等于装入器清单（绝对路径、受检面过滤后原序），判罚照常出红牌；注入缩水清单时引擎只收到该清单——受检面确实来自装入器而非缺省枚举（假引擎无视文件参数，清单断言是这条接缝唯一可观察的契约）。
